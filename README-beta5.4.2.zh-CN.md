# 仁王 1 · 飞缘魔操控工具

[English](README.md)

**当前版本：1.0.0 Beta 5.4.2。**

适配 Steam《仁王 完全版》1.24.08。Beta 5.4.2 增加九尾妖狐独立处决链，从当前已加载资源绑定原生动作、主辅动画和主辅事件，由游戏完成配对、伤害、死亡和剧情处理。精确新 Release EXE 已通过完整重启游戏、主菜单启用，用户确认正常处决、剧情继续及移动和菜单恢复；只读结束状态核对确认原生死亡及清理。保留八岐大蛇、菜单、属性、道具、梯子与交互兼容。

## 下载与使用

在 [Beta 5.4.2 Releases](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.5.4.2) 下载 Windows x64 EXE 与完整源码 ZIP。详见[发布说明](docs/releases/1.0.0-beta.5.4.2.md)和[构建说明](docs/BUILD.md)。发布附件由 GitHub Actions 独立构建和验证，哈希及来源保存在发布正文和源码包中；本地实机验证的精确 EXE 保留独立哈希。EXE 只需要 Windows 64 位和 .NET Framework 4.x，不需要 CE、Python 或源码包。

1. 升级后先退出并重启游戏，停在 **NEW GAME／CONTINUE 主菜单**。
2. 运行本版 EXE，启用飞缘魔后继续到地图或关卡。
3. 启用后可以关闭工具；每次重启游戏后再运行一次。
4. 切换威廉／飞缘魔时，在工具里选择角色，再返回主菜单继续，重新生成后生效。

受支持的旧 Beta 5.1、Hotfix 1、Beta 5.2、Beta 5.3、Beta 5.3.1、Beta 5.3.2、Beta 5.4、Beta 5.4.1 接入只读识别后要求重启；同一进程不要混用版本或 EXE／CT。Epic 和其他程序版本未适配。已支持 EXE 的 SHA-256 为 `0c3508c6b4d0696d84423949df9faccb3f9c6d93833854e1e17a78d66defc389`。
