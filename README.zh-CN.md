# 仁王 1 · 飞缘魔操控工具

[English](README.md)

**当前版本：1.0.0 Beta 1，预发布测试版。**

用于将 Steam《仁王 完全版》的主角替换为飞缘魔，保留她的模型和招式。本版整合已实测的交互修复，并将成长、防具与当前近战武器攻击加成叠加在 Boss 基础数值上。

## 下载与使用

在 [Beta 1 发布页](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.1) 下载 Windows x64 EXE 或 ZIP。ZIP 内有启动工具和使用说明，运行 EXE 不需要安装 CE 或 Python。

1. 从 Steam 正常启动游戏，停在 **NEW GAME / CONTINUE 主菜单**。
2. 运行工具，看到“已启用”后载入关卡。
3. 人物生成后变为飞缘魔，此时可以关闭工具。
4. 每次重新启动游戏后再运行一次工具。如果已用威廉进入关卡，先返回主菜单再启用。

同一次游戏重复运行会检查已启用状态。工具会核对程序和代码，遇到不匹配会停止。明确提示无法访问时，再尝试以管理员身份运行。

## 适配范围

- Windows 64 位、.NET Framework 4.x、Steam 完全版 **1.24.8**；游戏窗口显示 **1.24.08**。
- 已核对的游戏 EXE SHA-256：`0c3508c6b4d0696d84423949df9faccb3f9c6d93833854e1e17a78d66defc389`。
- Epic 版和其他程序版本未适配；版本名相同也不代表程序相同。
- 工具作用于当前游戏进程，使用时无需覆盖安装文件。游戏仍按原有流程存档，完整存取档和换关卡行为尚未全部验证。

## 本版功能与实测情况

- 人物已实测变为飞缘魔，可以基本移动、踢腿、挥伞和闪避。
- 已测试当前箱子、钥匙门、监狱门、单侧开启门与尸体取物。
- 飞行镜头、背包神篱碎片、木灵回家、背包御神水，以及本次血刀冢召唤狂尸已获实测确认。
- 成长、防具属性按 **Boss 基础数值＋原生加成** 重新计算，用户已确认脱装和重新装备后有变化。
- 当前近战武器的原生攻击增量叠加到飞缘魔攻击上。只装一把时使用这把武器，两槽有武器时只读取选中的一把。已加入右侧武器图标刷新兼容。

测试者当前键位：**J 踢腿、I 挥伞、K 闪避、Shift 恢复精力、Q＋空格起飞、1 吸血**。这些是当前设置的实际表现，其他设置可能不同。

## 已知限制

- 非人形 Boss 吸血仍有问题：已反馈的第一关 Boss 第二阶段抓取失败。
- 恢复与自身增益道具请从背包使用，快捷键可能与 Boss 技能冲突。御神水已确认；仙药实际回血及其他道具效果尚未逐一验证。
- 武器图标缓存和独立刷新路径已核对，最终屏幕图标显示尚未获得明确确认。
- 每项防具/武器词条、元素效果和实际命中伤害差异尚未逐项验证。
- 梯子、对话、神社、剧情、全部关卡切换和全部交互变体尚未验证。
- [CT](ct/Nioh_HinoEnma_1.24.8_Beta1.CT) 在 CE 内直接启用尚未实测，推荐 EXE；同一次游戏请选择其中一种方式。
- 本 Beta 未作 Windows Authenticode 签名。来源记录、构建证明和文件校验与 Windows 代码签名是不同的验证。
