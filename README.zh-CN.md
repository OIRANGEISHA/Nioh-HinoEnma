# 仁王飞缘魔 Beta 5.6.1

适配 Steam《仁王 完全版》1.24.08。本版修复主键盘数字 **9** 启动 99 武器时只有守护灵召唤的问题，恢复起手动画、冲击波、原生量表消耗和自然结束。99 期间，守护灵退场且角色恢复地面空闲后，再按 9 召唤守护灵的功能保留。

完整重启游戏，在 NEW GAME／CONTINUE 主菜单用 Beta5.6.1 EXE 启用飞缘魔；每次游戏重启需再次启用。运行 EXE 不需要 CE 或 Python。

本次精确 EXE 已通过完整重启实测：工具自动解析装备资源，没有临时补丁或手工绑定；只读核对全部 82 处补丁，首次按 9 前绑定为空，随后原生启动一次，能量从 1400 消耗至 0。用户确认动画、冲击波、量表显示、自然结束、移动和菜单全部正常，见[验收记录](docs/living-weapon-beta561-gameplay.json)。实测使用同一武器和守护灵，装备 type 11／family 2；其他装备、关卡尚未全面验证。

**已知未修复问题：忍术道具目前无法使用。**

保留此前大蛇、九尾处决，无间狱下一层交互、加载闪退、取消卡动作、玩家资源持有，以及木灵“引导至此岸”修复。历史实测记录保持原版本身份，本轮没有重新验证这些场景；联机外观也未全面验证。CT 已做离线载荷匹配，直接在 CE 中启用尚未实测。资源持有版本通过完整退出游戏结束接入。

本版 GitHub 发布保留精确冷测 EXE；源码 ZIP 从最终提交生成，Release 和 manifest 记录提交、tree 及下载读回的附件哈希。包内包含本次精确实测 EXE、匹配 CT、完整 UTF-8 源码及修复和验证记录。重新编译可能产生不同 EXE 哈希，不能直接继承精确文件的游戏实测结果。
