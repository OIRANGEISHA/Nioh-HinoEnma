# 仁王 1 · 飞缘魔操控工具

[English](README.md)

**当前版本：1.0.0 Beta 5.3.1，预发布测试版。**

适配 Steam《仁王 完全版》1.24.08。本版补上任务选择地图／据点中装备、状态预览的周身常世雾气，并修复关闭重开菜单、返回主菜单再继续后镜头取景失效。保留飞缘魔原生待机和去除威廉身体、防具叠层的处理。

## 下载与使用

用户已授权发布新的 [Beta 5.3.1 预发布版](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.5.3.1)，附件仅有 `Nioh-HinoEnma-1.0.0-beta.5.3.1-windows-x64.exe` 和 `Nioh-HinoEnma-1.0.0-beta.5.3.1-source.zip`。审核源码、标签及下载附件校验通过后才完成发布。使用 EXE 只需要 Windows 64 位和 .NET Framework 4.x，不需要 CE、Python 或源码包。

1. 升级后先退出并重启游戏，停在 **NEW GAME／CONTINUE 主菜单**。
2. 运行本版 EXE，启用飞缘魔后继续到地图或关卡。
3. 启用后可以关闭工具；每次重启游戏后再运行一次。
4. 切换威廉／飞缘魔时，在工具里选择角色，再返回主菜单继续，重新生成后生效。

受支持的旧 Beta 5.1、Hotfix 1、Beta 5.2、Beta 5.3 接入只读识别后要求重启；同一进程不要混用版本或 EXE／CT。Epic 和其他程序版本未适配。已支持 EXE 的 SHA-256 为 `0c3508c6b4d0696d84423949df9faccb3f9c6d93833854e1e17a78d66defc389`。

## 验证与开发

见 [Beta 5.3.1 说明](docs/releases/1.0.0-beta.5.3.1.md)、[构建方法](docs/BUILD.md)、[键位说明](docs/键位说明.md) 与 [验证记录](docs/validation-beta5.3.1.json)。历史版本记录保留原有范围。

本地源码通过 134 项回归和 41 项菜单测试（4280 次字节比较、15880 次合成 CPU 比较、12 组 ASLR 布局）。Debug 与 Release 各通过 28 项 C# 自检、852 次当前配置和 2928 次完整旧配置比较；原有 60 处基础通过 720 次载荷／跳转比较。离线校验使用合成记录与原生调用替身，不访问游戏。
