# 仁王1 飞缘魔 Beta 6.1

适用于 Steam《仁王：完整版》1.24.08，版本号为 `1.0.0-beta.6.1`。[下载 Beta 6.1 预发布版](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.6.1)：独立 Windows x64 EXE 和完整源码 ZIP。

新增风箭符、克金符和火炎龙术卷轴的已测试定义兼容，恢复原生施法、效果、次数扣除及火龙收招流程。用户已确认三项从背包使用均正常，移动、J／I 和数字 5 正常。此次实测针对运行中的修订；新 EXE 的离线验证单独记录，尚未完成该 EXE 的完整重启实测。

保留 Beta 6 道具修复及原有成长规则：0—750 级线性映射 1—4525 档；401 级起 Boss 基础生命 ×2、攻击 ×1.2，再叠加原生成长、装备和修正 LV 收益。精力、防御使用原生曲线，保留自身更高原生档位。此前九十九、守护灵、附魔、菜单预览及交互兼容继续保留。

运行本版 EXE 前完整重启游戏，在 NEW GAME／CONTINUE 主菜单启用，然后继续游戏；每次游戏重启后需重新运行工具。EXE 独立运行，无需 CE 或 Python。兼容道具从背包或**第一栏数字 2**使用，其余快捷位保留技能。常用键：**1 吸血、5 吼叫、9 九十九、F6 净化常世**。

兼容限已测试定义；其他同名变体、其他术及部分非关键道具尚未修复或验证，不代表所有道具、忍术或阴阳术均可使用。施法受击打断及全部战斗场景尚未全面验证。

源码包包含使用说明、键位、CT 和校验记录，保留历史包及历史实测身份。参见[Beta 6.1 版本说明](docs/releases/1.0.0-beta.6.1.md)、[构建方法](docs/BUILD.md)、[键位](docs/键位说明.md)、[成长实现](docs/GROWTH750-TRIAL.txt)和[来源说明](NOTICE.md)。
