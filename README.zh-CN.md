# 仁王 1 飞缘魔 Beta 5.6.2

[English](README.md)

适用于 Steam《仁王：完整版》1.24.08。Beta5.6.2 修复换存档或返回标题后再次载入时，数字 **9** 无法启动 99 武器的问题，并补齐不同近战武器的启动动作与事件资源兼容。保留起手动画、冲击波、原生量表消耗和自然结束；99 期间的守护灵召唤沿用既有行为。

完整退出并重启游戏，在“新游戏／继续游戏”主菜单运行本版 EXE 并启用飞缘魔。每次重启游戏后重新启用。支持 Windows x64、.NET Framework 4.x；独立 EXE 无需安装 CE 或 Python。升级时不要在同一进程叠加旧版。

修正版已在完整重启并实际二次载入后，以太郎太刀验证成功；用户确认动画、冲击波、量表显示和消耗、结束后的移动及菜单全部正常。7 类武器资源另通过离线检查，尚未逐类完成实机测试。Beta5.6.2 重新编译了版本信息，全部 82 处运行补丁在 12 种地址布局下与该实测文件逐字节一致；新版本 EXE 本身没有重复实机测试。详见[验收记录](docs/living-weapon-beta562-gameplay.json)。

**已知问题：忍术道具目前无法使用，后续修复。** 下载存档中的非标准装备记录未覆盖，武器品质本身没有限制。联机外观尚未全面验证。

包含此前大蛇、九尾处决、无间狱换层／取消／坐船资源寿命，以及木灵“引导至此岸”修复；历史实测记录保留原版本身份，本轮未重跑这些场景。CT 与 EXE 补丁已离线核对，CE 直接启用仍未实机验收，同一进程只选择一种启用方式。
