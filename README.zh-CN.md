# 仁王1 飞缘魔 Beta 6.2

适用于 Steam《仁王：完整版》1.24.08，版本 `1.0.0-beta.6.2`。下载：[Beta 6.2 发布页](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.6.2)。Release 仅提供独立 Windows x64 EXE 与完整源码 ZIP。

本版修复**木灵变化术卷轴**和**宿心升华符**。木灵变化术可正常变身，移动或攻击后恢复飞缘魔；宿心升华符读取当前近战武器爱用度，保留至少 300 的原生要求、攻击／幸运增益、效果结束时的爱用度消耗及复用限制。两项修复已在运行中的游戏里确认正常。

保留 Beta 6.1.4 的通用忍术／阴阳术动作分派、苦无实际投出、连续使用与受击恢复，以及此前全部道具、成长、九十九、附魔、菜单预览和交互修复。

完整重启游戏，停在 NEW GAME／CONTINUE 主菜单，运行 EXE 启用飞缘魔后继续；每次重启游戏需重新启用。无需 CE 或 Python。兼容道具从背包或**第一栏数字 2**使用，其他快捷位保留技能。常用键：**1 吸血、5 吼叫、9 九十九、F6 净化常世**。

成长规则保持：0—750 级线性映射 1—4525 档，401 级起 Boss 基础生命 ×2、主攻击 ×1.2，再叠加原生成长、装备与体力／攻击／防御／幸运修正 LV。精力、防御使用原生曲线，并保留自身更高原生档位。

**仍有部分忍术、阴阳术和非关键道具未修复或未验证。** 13 类、132 条定义的通用分派覆盖不等于全部效果实测。其他变身、替身／死亡触发、缩地及特殊资源消耗仍需分别验证。木灵受击分支本轮仅离线检查；新 EXE 的完整重启实测尚未进行。

源码包包含说明、键位、CT、构建与验证记录。参见[版本说明](docs/releases/1.0.0-beta.6.2.md)、[构建方法](docs/BUILD.md)、[键位](docs/键位说明.md)、[成长实现](docs/GROWTH750-TRIAL.txt)和[来源说明](NOTICE.md)。
