# 仁王1 飞缘魔 Beta 6

适用于 Steam《仁王：完整版》1.24.08，版本号为 `1.0.0-beta.6`。下载请前往 [Beta 6 发布页](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.6)。

新增切腹短刀、粪球、高贵的粪球、天狗的团扇、石头、火药弹、焙烙弹、焚火油壶、御箭护符和已测试迟钝符的兼容。切腹短刀的死亡与神社复活，以及其余道具的使用效果均已由用户实测确认。本批修订在运行中的游戏里通过测试；新 Beta 6 EXE 仅完成离线检查，尚未完整重启实测。

保留原有成长规则：0—750 级线性映射 1—4525 档；401 级起 Boss 基础生命 ×2、攻击 ×1.2，再叠加原生成长、装备和修正 LV 收益。精力、防御使用原生曲线，保留自身更高原生档位。此前九十九、守护灵、附魔、菜单预览及交互兼容继续保留。

运行本版 EXE 前完整重启游戏，在 NEW GAME／CONTINUE 主菜单启用，然后继续游戏；每次游戏重启后需重新运行工具。EXE 独立运行，无需 CE 或 Python。兼容道具从背包或**第一栏数字 2**使用，其余快捷位保留技能。常用键：**1 吸血、5 吼叫、9 九十九、F6 净化常世**。

迟钝符兼容限本次已测试的定义；其他迟钝符变体、其他术及部分非关键道具尚未修复或验证，不代表所有道具、忍术或阴阳术均可使用。

GitHub 附件仅提供原本地 EXE 和最终提交的源码 ZIP；源码包包含使用说明、键位、CT 和校验记录。参见[Beta 6 版本说明](docs/releases/1.0.0-beta.6.md)、[构建方法](docs/BUILD.md)、[键位](docs/键位说明.md)、[成长实现](docs/GROWTH750-TRIAL.txt)和[来源说明](NOTICE.md)。
