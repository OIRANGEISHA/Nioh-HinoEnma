# 仁王1 飞缘魔 Beta 6.1.4

适用于 Steam《仁王：完整版》1.24.08，版本 `1.0.0-beta.6.1.4`。下载请前往 [Beta 6.1.4 发布页](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.6.1.4)。Release 仅提供独立 Windows x64 EXE 与最终提交源码 ZIP 两个附件。

本次加入忍术／阴阳术的通用动作兼容：按道具原生类别选择施放动作，沿用游戏本身的投射物、效果和消耗逻辑。修复苦无只有动作却没有投出、连续使用失效，以及施放中或结束后受击误触撑伞、飞起或吼叫的问题。苦无的实际投出、连续使用、受击恢复和后续移动／攻击已由用户确认正常。

保留 Beta 6.1.3 的全部修复，包括粘液罐、散变符连续施放、封力／活源／封气／五属性弹符／发气，以及宿心解放符的武器爱用度读取与光刃。宿心解放符仍要求至少 300 爱用度，使用后沿用原生消耗。

运行本版 EXE 前完整重启游戏，在 NEW GAME／CONTINUE 主菜单启用，然后继续游戏；每次游戏重启后需重新运行工具。EXE 独立运行，无需 CE 或 Python。兼容道具从背包或**第一栏数字 2**使用，动作结束后松开再按即可尝试连续使用。常用键：**1 吸血、5 吼叫、9 九十九、F6 净化常世**。其他快捷位保留技能。

成长仍为 0—750 级线性映射 1—4525 档，401 级起 Boss 基础生命 ×2、主攻击 ×1.2，再叠加原生成长、装备与体力／攻击／防御／幸运修正 LV。精力、防御使用原生曲线，并保留自身更高原生档位。此前九十九、守护灵、附魔、菜单预览及交互修复均保留。

**仍有部分忍术、阴阳术和道具未修复或未验证。** 通用分派已离线覆盖 13 类、132 条定义，这不代表全部实际效果都已实测。木灵变化、替身／死亡触发、宿心升华、缩地、放置物件及特殊资源消耗等需分别验证，见[特殊术法核对记录](docs/general-jutsu-special-cases.json)。本批代码在运行中的游戏里抽测；新 EXE 的完整重启实测尚未进行。

源码包包含使用说明、键位、CT、构建与验证记录。参见[版本说明](docs/releases/1.0.0-beta.6.1.4.md)、[构建方法](docs/BUILD.md)、[键位](docs/键位说明.md)、[成长实现](docs/GROWTH750-TRIAL.txt)和[来源说明](NOTICE.md)。
