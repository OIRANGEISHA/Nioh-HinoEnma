# 仁王1 飞缘魔 Beta 6.1.3

适用于 Steam《仁王：完整版》1.24.08，版本 `1.0.0-beta.6.1.3`。下载请前往 [Beta 6.1.3 发布页](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.6.1.3)。Release 仅提供独立 Windows x64 EXE 和最终提交的完整源码 ZIP 两个附件。

合入此前尚未打包的修复：**粘液罐、散变符**，以及**封力符、活源符、封气符、宿心解放符、火／水／风／雷／土弹符、发气符**。散变符可在动作结束后连续施放，已连续测试四次。

宿心解放符会读取当前装备武器的实际爱用度，沿用原生光刃、次数扣除和爱用度消耗；仍要求爱用度至少 300。使用一次后爱用度不足而按钮变灰属于原生限制，需要换用满足条件的武器或重新提升爱用度。

保留五种禁属性晴明符、风箭符／克金符效果、道具受击恢复、移动后连续施法、护灵招来符和污泥罐等既有修复。本批道具效果及使用后移动、招式已在运行中的游戏里确认；新 EXE 单独进行离线验证，尚未完成该 EXE 的完整重启实测。

运行本版 EXE 前完整重启游戏，在 NEW GAME／CONTINUE 主菜单启用，然后继续游戏；每次游戏重启后需重新运行工具。EXE 独立运行，无需 CE 或 Python。兼容道具从背包或**第一栏数字 2**使用，其余快捷位保留技能。常用键：**1 吸血、5 吼叫、9 九十九、F6 净化常世**。

保留此前九十九、守护灵、附魔、菜单预览及交互修复。成长仍为 0—750 级线性映射 1—4525 档，401 级起 Boss 基础生命 ×2、主攻击 ×1.2，再叠加原生成长、装备与体力／攻击／防御／幸运修正 LV。精力、防御使用原生曲线，并保留自身更高原生档位。

**仍有部分阴阳术的使用尚未修复。** 兼容范围限已核对的定义。其他同名变体、其他术和部分非关键道具尚未修复或验证；全部武器种类与道具受击组合未逐一实测。

源码包包含使用说明、键位、CT 与验证记录。参见[版本说明](docs/releases/1.0.0-beta.6.1.3.md)、[构建方法](docs/BUILD.md)、[键位](docs/键位说明.md)、[成长实现](docs/GROWTH750-TRIAL.txt)和[来源说明](NOTICE.md)。
