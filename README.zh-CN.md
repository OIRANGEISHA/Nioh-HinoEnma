# 仁王 1 · 飞缘魔操控工具

[English](README.md)

**当前版本：1.0.0 Beta 3，预发布测试版。**

用于将 Steam《仁王 完全版》的主角替换为飞缘魔，保留她的模型和招式。Beta 3 对应本地 0.44，整合 Beta 2 本地 0.35 之后的护符、指定招式附魔、守护灵回收、四项等级成长及温泉动作修复；成长、装备和选中武器的原生加成继续叠加。

## 下载与使用

发布资产提供后，在 [Beta 3 发布页](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.3) 下载 Windows x64 EXE 或 ZIP。ZIP 内有启动工具和使用说明，运行 EXE 不需要安装 CE 或 Python。

1. 从 Steam 正常启动游戏，停在 **NEW GAME / CONTINUE 主菜单**。
2. 运行工具，看到“下次载入：飞缘魔”后载入关卡。
3. 人物生成后变为飞缘魔，此时可以关闭工具。
4. 切换角色时，在工具中选择“切换回威廉”或“切换为飞缘魔”，返回主菜单后重新载入。每次重启游戏后再运行一次工具。

同一次游戏重复运行会识别已有接入并保留角色选择；重启游戏后重新启用，默认选择飞缘魔。工具会核对程序和代码，遇到不匹配会停止。明确提示无法访问时，再尝试以管理员身份运行。如需回退，先退出游戏，再使用保留原版的 [Beta 1 发布包](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.1)。

## 适配范围

- Windows 64 位、.NET Framework 4.x、Steam 完全版 **1.24.8**；游戏窗口显示 **1.24.08**。
- 已核对的游戏 EXE SHA-256：`0c3508c6b4d0696d84423949df9faccb3f9c6d93833854e1e17a78d66defc389`。
- Epic 版和其他程序版本未适配；版本名相同也不代表程序相同。
- 工具作用于当前游戏进程，使用时无需覆盖安装文件。游戏仍按原有流程存档，完整存取档和换关卡行为尚未全部验证。

## Beta 3 新增修复

- 温泉接回原生坐下、等待、起身及离开。当前池的动作、Buff 和离开后移动／J／I 已确认，同版本威廉在同处也会短等后自动起身；不声称精确时长全等或全部池已验证。
- 缠雷／缠火护符和道祖神护符的背包使用已确认，附魔护符可重复使用。用户确认九十九期间麻针、冲撞本体和吸血有元素效果；吼叫原有异常与附加物件原效果保留，本版排除吼叫追加第二元素。
- 祸斗的神社召回和死亡刀冢拾回走原生归还流程，归还后数字 9 启动和攻击已确认；其他守护灵待验证。
- 生命、精力、攻击、防御使用原生 Boss 曲线：1 级→档位 1、400 级→档位 1410 线性映射并向下取整。有效保存等级范围 1—750，高于 400 暂按 400 封顶，保留原场景中更高档位；成长、装备及选中武器加成继续叠加。重新装备防具并关闭菜单或重新载入可触发正常刷新；不改存档等级、点数、场景档位或直接设置当前生命，重复刷新重算基础加成。

## 保留功能与实测范围

- 人物已实测变为飞缘魔，可以基本移动、踢腿、挥伞和闪避。
- 已测试当前箱子、钥匙门、监狱门、单侧开启门与尸体取物。
- 飞行镜头、背包神篱碎片、木灵回家、背包御神水，以及本次血刀冢召唤狂尸已获实测确认。
- 成长、防具属性按 **Boss 基础数值＋原生加成** 重新计算，用户已确认脱装和重新装备后有变化。
- 当前近战武器的原生攻击增量叠加到飞缘魔攻击上。只装一把时使用这把武器，两槽有武器时只读取选中的一把。已加入右侧武器图标刷新兼容。
- 已反馈的妖鬼、敷次郎和怨灵鬼可以完成抓住吸血动画；不代表所有妖怪或 Boss 都已验证。
- 原生上梯、下梯和离梯已实测通过，攀爬不会再误触吼叫；离梯后移动、J／I 和数字 5 正常。
- F6 独立净化周围常世；数字 5 直接发动地面及空中吼叫，Alt 保留飞扑、俯冲。
- 背包忍者的遗发、小灵石和恢复／自身增益道具的兼容；已反馈的道场遗发、残心、净化、武器切换和九十九步骤可继续，射击教学通过击败目标继续。
- 数字 9 在满槽时启动原生九十九，保留飞缘魔招式。已确认原生属性强化、守护灵攻击和重复召唤，包括测试者使用无限九十九修改器的情况；实际命中伤害数值未测。
- 修复最新反馈的数字 9 满槽仍无法启动：按原生 32 位宽度读取资源 ID，避免将旁边未清理的填充数据误读进去。本次修复已通过离线回归，用户已确认修正后的启动、守护灵攻击和退场后重复召唤正常。

测试者当前键位：**J 踢腿、I 挥伞、K 闪避、Shift 恢复精力、Q＋空格起飞、1 吸血、5 吼叫、F6 净化常世、9 原生九十九／守护灵召唤**。空格兼容道场残心与净化；武器切换教学使用空格＋2／3（近战）和空格＋1／4（远程）；T 完成已反馈的九十九教学操作并保留原有攻击。这些是当前设置的实际表现，其他设置可能不同。

## 已知限制

- 路标符标记尚未修复，吼叫追加元素排除；麻针原麻痹力度、具体元素伤害／回血和全部空中变体未量测或验证。
- 当前池的飞缘魔等待采样约 0.062／0.063 秒、威廉约 0.079 秒，不证明精确时长相同，也不追认旧飞缘魔记录的退出分支；其他池待验证。
- 实际花精华升级、新成长存读档及战斗伤害量测待验证；攻击标量不等于实际命中伤害，精力派生值不是已量测最终精力条上限。修改器可单独覆盖运行时数值。
- 道具请从背包使用，数字 1—4 与飞缘魔技能冲突。御神水、已反馈的遗发与小灵石已确认；每种恢复／增益和忍术道具尚未逐一验证。
- 武器图标缓存和独立刷新路径已核对，最终屏幕图标显示尚未获得明确确认。
- 每项防具/武器词条、元素效果和实际命中伤害差异尚未逐项验证。
- 梯子和道场结果限于已反馈的位置；其他梯子、对话、神社、剧情、全部关卡切换和交互变体尚未全面验证。武器切换教学兼容不代表实际切换 Boss 武器，原生射击流程尚未接入。
- 九十九保留飞缘魔身体与招式，没有威廉完整起手动画和武器外观；召唤守护灵没有重现威廉原版的额外精力消耗。其他守护灵、手柄及完整战斗／换关卡情况尚未全面验证。
- [CT](ct/Nioh_HinoEnma_1.24.8_Beta3.CT) 在 CE 内直接启用尚未实测，推荐 EXE；同一次游戏请选择其中一种方式，不支持混用不同版本。
- 最终公开 Beta 3 EXE 在新游戏进程中的首次接入仍待单独实测；离线检查和已有接入的识别不证明冷首次接入通过。
- 本 Beta 未作 Windows Authenticode 签名。来源记录、构建证明和文件校验与 Windows 代码签名是不同的验证。
