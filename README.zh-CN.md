# 仁王1 飞缘魔 Beta5.6.3

适用于Steam《仁王：完整版》1.24.08。本版已加入750级成长与四类修正LV兼容，保留Beta5.6.2的99武器及既有交互修复。

0—750级映射1—4525档；401级起Boss基础生命×2、攻击×1.2，再叠加原生成长、装备和修正收益。精力、防御使用原生曲线。补回固定攻击收益，避免攻击修正LV漏算。

运行本版EXE前完整重启游戏，在主菜单启用，然后继续游戏。EXE独立运行，无需CE或Python。道具使用第一栏数字2或背包，其余快捷位保留技能。

本次成长载荷已在750级角色上实机确认；新EXE尚未单独冷启动实测。[下载 Beta5.6.3](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.5.6.3)。忍术道具及部分非关键道具仍未修复。
