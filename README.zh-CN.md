# 仁王飞缘魔 Beta 5.6

适配 Steam《仁王 完全版》1.24.08。包含无间狱前往下一层无反应、加载闪退、取消后卡动作修复，玩家资源持有修复，以及木灵“引导至此岸”交互无反应修复。原样Beta5.5去程乘船已单独复测正常。

完整重启游戏，在NEW GAME／CONTINUE主菜单用Beta5.6 EXE启用飞缘魔。每次游戏重启需再次启用；运行EXE不需要CE或Python。

已知未修复问题：99武器释放缺少动画及冲击波效果，当前错误地把两者变成召唤守护灵；忍术道具当前无法使用。这两项问题后续修复。

Beta5.6按用户要求更新版本，82处原生补丁与完整重启实测成功的Beta5.5.1一致。其精确文件实测记录保持原样，见[验收](docs/guide-restart-gameplay.json)，不把旧EXE身份写成新EXE实测。新版本另有编译导出、完整239项回归及9组ASLR载荷等价核对。

见[使用说明](docs/使用说明.txt)、[本版记录](docs/releases/1.0.0-beta.5.6.md)、[构建](docs/BUILD.md)及[键位](docs/键位说明.md)。去程乘船与木灵引导是两种交互，分别记录；其他层数、难度、交互变体、联机外观尚无覆盖性测试。Release提供EXE和完整源码ZIP，CI附件与本地实测文件保留各自哈希和来源。
