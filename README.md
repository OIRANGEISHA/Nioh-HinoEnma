# Nioh Hino-Enma Beta 6.1

[简体中文](README.zh-CN.md)

Beta 6.1 (`1.0.0-beta.6.1`) for Steam Nioh: Complete Edition 1.24.08. [Download the Beta 6.1 Pre-release](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.6.1): standalone Windows x64 EXE and complete source ZIP.

Adds compatibility for the tested Wind Shot Talisman, Weakness Talisman and Flame Dragon Scroll definitions. Inventory use now follows their native casting, effect and stock-consumption flows, including Flame Dragon's recovery. The user confirmed all three effects and normal movement, J/I and digit 5 in the running game. The new EXE has separate offline verification; a complete game restart with this exact EXE has not been tested.

Preserves Beta 6's item repairs and the growth and equipment rules: levels 0–750 map linearly to native Hino-Enma growth indices 1–4525. From level 401, the Boss HP basis is doubled and main attack multiplied by 1.2, before native player, equipment and Focus bonuses. Ki and defense use native curves; a higher native Boss index is retained.

Restart the game, stop at the title menu, run the EXE and enable Hino-Enma, then continue. Repeat after each game restart. No Python or Cheat Engine is required for the EXE. Use compatible items from inventory or shortcut **2 on the first item bar**. Main keys: **1** life drain, **5** roar, **9** Living Weapon, **F6** purification.

Other item or jutsu definitions, including untested variants with the same names, and some non-critical items remain unsupported or unverified. This update does not establish support for every ninjutsu or onmyo spell. Cast interruptions and all combat situations have not been fully tested.

Usage, key bindings, CT and verification records are included in the source archive. Historical packages and evidence retain their original identities. See [Beta 6.1 notes](docs/releases/1.0.0-beta.6.1.md), [build instructions](docs/BUILD.md), [keys](docs/键位说明.md), and [credits](NOTICE.md).
