# Nioh Hino-Enma Beta 6.2

[简体中文](README.zh-CN.md)

For Steam Nioh: Complete Edition 1.24.08, Windows x64. Download the standalone EXE or complete source ZIP from the [Beta 6.2 release](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.6.2). These are the only two Release attachments.

Adds **Kodama Transformation** and **Soul Purge** compatibility. Transformation retains native item consumption and restores Hino-Enma on movement or attack. Soul Purge reads the selected melee weapon, retains the 300-familiarity minimum, native attack/luck buffs, reuse restrictions and familiarity consumption when the effect ends. Both fixes were confirmed in the running game.

Retains Beta 6.1.4 general ninjutsu/Onmyo routing, Kunai projectiles, consecutive use and injury recovery, plus earlier item, growth, Living Weapon, guardian, elemental, preview and interaction fixes.

Restart the game, stop at the title menu, run the EXE and enable Hino-Enma, then continue. Repeat after each game restart. No Python or Cheat Engine is required. Use compatible items from inventory or shortcut **2 on the first item bar**. Main keys: **1** life drain, **5** roar, **9** Living Weapon, **F6** purification. Other item slots retain Hino-Enma skills.

Levels 0–750 map linearly to native growth indices 1–4525. From level 401 the Boss HP basis is doubled and main attack multiplied by 1.2, before native player, equipment and Focus bonuses. Ki and defense use native curves; a higher native Boss index is retained.

**Some ninjutsu, Onmyo magic and non-critical items remain unsupported or unverified.** The 13-category/132-definition offline dispatcher coverage does not mean all effects were gameplay-tested. Other transformations, death triggers, Earthfolding and special costs still require individual validation. Kodama injury routing has offline checks only this round. The exact newly built EXE has not undergone a complete game-restart test.

Usage, keys, optional CT, build tools and verification records are in the source ZIP. See [release notes](docs/releases/1.0.0-beta.6.2.md), [build instructions](docs/BUILD.md), [keys](docs/键位说明.md) and [credits](NOTICE.md).
