# Nioh Hino-Enma Beta 6.1.3

[简体中文](README.zh-CN.md)

Beta 6.1.3 (`1.0.0-beta.6.1.3`) for Steam Nioh: Complete Edition 1.24.08. Download the standalone Windows x64 EXE or complete source ZIP from the [Beta 6.1.3 release](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.6.1.3). The release has exactly these two attachments.

Adds the tested Sticky Pot and Dispersal Talisman, including four consecutive Dispersal casts after each animation ends. Adds Devigorate, Oasis, Lifeseal, Soul Release, the five elemental Shot talismans and Ki Burst. Soul Release uses the equipped weapon's saved familiarity for its native eligibility, projectile and consumption; it still requires at least 300 familiarity and consumes it when used.

Retains the five Seimei resistance talismans, Wind Shot/Weakness projectile repair, item interruption and movement-to-recast fixes, Guardian Talisman and Sludge Jar, and all earlier repairs. The newly integrated effects were confirmed in the running game, including normal movement and attacks afterward. Source and compiled payload equivalence are checked separately; a complete restart with this exact new EXE has not been tested.

Restart the game, stop at the title menu, run the EXE and enable Hino-Enma, then continue. Repeat after each game restart. No Python or Cheat Engine is required for the EXE. Use compatible items from inventory or shortcut **2 on the first item bar**. Main keys: **1** life drain, **5** roar, **9** Living Weapon, **F6** purification.

Preserves earlier Living Weapon, guardian, element, preview and interaction repairs. Levels 0–750 map linearly to native growth indices 1–4525. From level 401, the Boss HP basis is doubled and main attack multiplied by 1.2, before native player, equipment and Focus bonuses. Ki and defense use native curves; a higher native Boss index is retained.

**Some Onmyo magic still cannot be used and has not been fixed.** Other item or jutsu definitions, including untested variants with the same names, and some non-critical items remain unsupported or unverified. Not every weapon family or item interruption was tested individually.

Usage, key bindings, CT and verification records are included in the source archive. See [release notes](docs/releases/1.0.0-beta.6.1.3.md), [build instructions](docs/BUILD.md), [keys](docs/键位说明.md) and [credits](NOTICE.md).
