# Nioh Hino-Enma Beta5.6.3

[简体中文](README.zh-CN.md)

Beta pre-release for Steam Nioh: Complete Edition 1.24.08. Levels0–750 map to native Hino-Enma growth indices1–4525. From level401, the Boss-only HP basis is doubled and main attack multiplied by1.2, before native player/equipment/Focus bonuses. Ki and defense use native curves. Selected-weapon flat attack now retains native Focus attack bonuses.

The tested growth payload is included with all previous Beta5.6.2 fixes. Its live750-level equipment refresh was confirmed; this exact executable has not undergone a fresh-process gameplay test. [Download Beta5.6.3](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.5.6.3). Ninjutsu and some non-critical item uses remain unsupported.

Restart the game, stop at the title menu, run the EXE, then continue. No Python or Cheat Engine is required for the EXE. Use items from inventory or shortcut2 on the first item bar. Main keys:1 life drain,5 roar,9 Living Weapon, F6 purification.
