# Nioh Hino-Enma Beta 6

[简体中文](README.zh-CN.md)

Beta 6 (`1.0.0-beta.6`) for Steam Nioh: Complete Edition 1.24.08. Download the EXE or source from the [Beta 6 pre-release](https://github.com/OIRANGEISHA/Nioh-HinoEnma/releases/tag/v1.0.0-beta.6).

Adds compatibility for the Harakiri Sword, Dung Ball, Noble Dung Ball, Tengu's Fan, Stone, Kayaku-dama, Horoku-dama, Burning Oil Jar, Arrowproof Amulet and the tested Sloth Talisman definition. These repairs passed user gameplay tests in the running game. The new Beta 6 EXE has offline checks only; it has not been tested after a complete game restart. Other Sloth variants, other jutsu and some non-critical items remain unsupported or unverified.

Preserves the previous growth and equipment rules: levels 0–750 map linearly to native Hino-Enma growth indices 1–4525. From level 401, the Boss HP basis is doubled and main attack multiplied by 1.2, before native player, equipment and Focus bonuses. Ki and defense use native curves; a higher native Boss index is retained.

Restart the game, stop at the title menu, run the EXE and enable Hino-Enma, then continue. Repeat after each game restart. No Python or Cheat Engine is required for the EXE. Use compatible items from inventory or shortcut **2 on the first item bar**. Main keys: **1** life drain, **5** roar, **9** Living Weapon, **F6** purification.

The GitHub release contains exactly two attachments: the original locally verified EXE and a source ZIP from the final commit. Usage, key bindings, CT and verification records are included in the source archive. Original local packages and historical records retain their original identities.
