# 1.0.0 Beta 6.1.2

新增禁火、禁水、禁风、禁雷、禁土晴明符兼容，解决背包使用后没有动作或增益的问题。保留原生施法、增益和复用规则；这五种定义没有显示数量，不以数量减少作为验收条件。

五种符的动作和增益已由用户确认。记录捕捉到禁火符三次施法受击，均进入正确的公共受击动作，恢复后可再次使用。五种符共用这一施法路径，尚未分别覆盖所有敌人和每类打断。

保留 Beta 6.1.1 的风箭符／克金符实际效果、已支持道具受击恢复、移动后连续施法，以及护灵招来符、污泥罐修复。成长、装备、九十九、守护灵、菜单预览和交互兼容沿用此前实现。

兼容道具可从背包或**第一栏数字 2**使用，其他快捷位保留飞缘魔技能。常用键：1 吸血，5 地面／空中吼叫，9 九十九与守护灵，F6 净化常世，J 踢腿，I 挥伞。部分非关键道具、其他同名变体和术仍未修复或验证。

本地交付独立 Windows x64 EXE 与完整源码 ZIP，说明、键位和校验信息随包附带，CT 位于源码包。启动本版前完整重启游戏，在 NEW GAME／CONTINUE 主菜单启用；EXE 使用者无需 Python 或 Cheat Engine。

本版运行代码与用户已验证的临时修订逐一比较，保留 82 处原生入口及原分配布局。新 EXE 单独完成离线校验；尚未对这个 EXE 进行完整重启实测。源码包来自本地受检快照，本次未推送 GitHub。
