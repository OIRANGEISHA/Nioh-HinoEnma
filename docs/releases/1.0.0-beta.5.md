# 1.0.0 Beta 5

适配 Steam《仁王 完全版》1.24.08，对应本地 v0.58。预发布测试版，2026-10-09。

## 本次更新

- 兼容守护灵呼唤符、火男面具、海螺、黄泉水罐、寄宿木灵之碗、神篱之木和招灵蜡烛。用户已确认这七种已反馈道具的相关召唤、投放或中断任务效果；招灵蜡烛在死亡复活、守护灵丢失时测试，召回后守护灵攻击正常。
- 恢复盐的消耗、撒盐特效和已反馈的妖怪精力命中，并处理已反馈的使用后受击恢复异常。最新一轮使用与受击测试正常，移动和攻击正常。其他受击路径已有离线回归，仍需实际游戏验证。
- 修复工具对较长已接入补丁的读取：分块读取并核对完整长度与地址范围，部分读取仍会拒绝。
- 更正快捷道具说明：**装备到第一栏的 2 号快捷位**。其他快捷位置继续使用原有飞缘魔技能或动作。

Beta 5 adds the seven reported special-item effects and Salt compatibility, based on local 0.58. The latest reported Salt use and interruption test passed. The additional Common 205/85 interruption routes have CPU regression coverage only and have not been observed in gameplay; this is not complete coverage of every Salt/enemy combination.

## 下载与使用

Release 仅上传两个附件：

- `Nioh-HinoEnma-1.0.0-beta.5-windows-x64.exe`：直接运行的 Windows x64 工具，不需要 CE 或 Python。
- `Nioh-HinoEnma-1.0.0-beta.5-source.zip`：完整公开源码、构建方法、使用和键位说明及构建记录。

从 Steam 启动游戏，停在 **NEW GAME / CONTINUE 主菜单**，运行 EXE 后载入关卡。角色切换需要返回主菜单再载入；每次重新启动游戏后再运行工具。同一次游戏不要混用不同版本或 EXE／CT。

## 保留功能与键位

继承 Beta 4.1 的门闩门、NPC 交谈、倒地誾千代救助、路标符、敌方飞缘魔清理，以及此前的梯子、温泉、兼容道具、守护灵和属性修复。成长、装备及选中武器加成继续叠加到 Boss 基础值，不替换基础值。

以下沿用当前已测试的游戏键位，数字键指主键盘数字行；更改游戏设置后操作可能不同。

| 按键 | 操作 |
| --- | --- |
| W / A / S / D | 移动 |
| J | 踢腿 |
| I | 挥伞 |
| K | 撤步 / 闪避 |
| Shift | 恢复精力 |
| Q + 空格 | 起飞 |
| Alt | 飞扑 / 俯冲 |
| 1 | 吸血 |
| 2（第一栏道具快捷位） | 使用兼容道具；当前唯一支持的道具快捷位 |
| 5 | 地面和空中吼叫 |
| F6 | 净化附近常世；松开再按可再次触发 |
| 9 | 地面空闲、守护灵槽满时启动九十九并召唤守护灵攻击 |
| 游戏交互键，随后 W / S | 进入梯子后向上 / 向下攀爬 |

九十九期间，等守护灵退场、人物恢复地面空闲，再松开并按 9 可重复召唤。**快捷道具放到第一栏的 2 号快捷位**；其他快捷位置会触发飞缘魔技能或动作。兼容道具也可从背包选择“使用”。道场空格残心、空格＋2／3 近战切换教学、空格＋1／4 远程切换教学和 T 九十九教学保持；教学兼容不代表完整原生换武器或射击支持。

## 验证与限制

- 本地 v0.58 新增 **23 项原生 CPU 回归通过**，使用私有已核对的原生代码输入。公开源码另有 **23 项 CPU 检查通过**（8 项保留门实例、5 项新增特殊道具、10 项新增盐检查），使用合成记录及显式 Win64 替身，不执行原生伤害／事件引擎或背包提交。公开 23 项与本地 23 项分别记录，不读取或分发私有游戏代码与原始日志，也不等同完整原生流程覆盖。
- 公开 Debug／Release 各通过 **21 项 EXE 自检及 600 次 EXE／源码布局比对**（50 个补丁 × 12 组布局），不访问游戏；实际完成结果记录在 [Beta 5 验证](https://github.com/OIRANGEISHA/Nioh-HinoEnma/blob/v1.0.0-beta.5/docs/validation-beta5.json)。此前冻结证明不声称全部重新运行。
- 用户确认包括七种新道具及本次盐正常使用／受击恢复。盐的新增 Common 205／85 受击路径尚未在实测中出现，不能据此认定所有盐与敌人组合都已修复。
- **部分非关键道具使用仍未修复**。全部道具、词条、NPC、守护灵、地图和交互变体尚未逐一验证；动作仍可能固定大笑，吼叫不叠加额外元素。
- 最终公开 EXE 已通过当前 0.58 接入的实游戏只读识别；新游戏进程首次接入尚未单独实测；本版 CT 在 CE 内直接启用未测。Windows Beta 未作 Authenticode 签名。

Offline source/build checks, private native-code regressions and user gameplay reports have distinct scope. Public packaging does not establish complete mission, item, save/load or cold first-enable coverage.

源提交、附件 SHA-256、组件和构建记录保存在源码包及发布页。Beta 4.1 和更早版本的标签、资产及历史记录保持原样。角色替换源自用户提供的 Bryanyora Character Change CT；工具不附带游戏程序、游戏资源或私人内存记录。
