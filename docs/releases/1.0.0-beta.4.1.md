# 1.0.0 Beta 4.1

适配 Steam《仁王 完全版》1.24.08，对应本地 v0.51。预发布测试版，2026-10-09。

## 本次修复

修复已反馈的信贵山蜘蛛任务门闩门：旧固定实例判断改为按原生门闩类型判断；其他请求、所有权和资源保护保持。

用户已确认信贵山该门可以打开；这次确认不代表全部地图和门变体已经验证。

The reported latched door in the Shigisan spider mission now opens. Replace the fixed-instance check with the native latched-door type check, retaining request, ownership and resource guards. User confirmation covers the reported door, not every map or variant.

## 下载与使用

Release 仅上传两个附件：

- `Nioh-HinoEnma-1.0.0-beta.4.1-windows-x64.exe`：直接运行的 Windows x64 工具，不需要 CE 或 Python。
- `Nioh-HinoEnma-1.0.0-beta.4.1-source.zip`：完整公开源码、构建方法、使用和键位说明及构建记录。

从 Steam 启动游戏，停在 **NEW GAME / CONTINUE 主菜单**，运行 EXE 后载入关卡。角色切换也需要返回主菜单再载入；每次重新启动游戏后再运行工具。同一次游戏不要混用不同版本或 EXE／CT。

## 保留功能与键位

继承 Beta 4 的 NPC 交谈、倒地誾千代救助、路标符、敌方飞缘魔清理，以及此前的梯子、温泉、兼容道具、守护灵和属性修复。成长、装备及选中武器加成继续叠加到 Boss 基础值，不替换基础值。

以下沿用当前已测试的游戏键位，数字键指主键盘数字行；更改游戏设置后操作可能不同。

| 按键 | 操作 |
| --- | --- |
| W / A / S / D | 移动 |
| J | 踢腿 |
| I | 挥伞 |
| K | 撤步 / 闪避 |
| Shift | 恢复精力 |
| Q + 空格 | 起飞 |
| Alt | 飞扑 / 俯冲 |
| 1 | 吸血 |
| 5 | 地面和空中吼叫 |
| F6 | 净化附近常世；松开再按可再次触发 |
| 9 | 地面空闲、守护灵槽满时启动九十九并召唤守护灵攻击 |
| 游戏交互键，随后 W / S | 进入梯子后向上 / 向下攀爬 |

九十九期间，等守护灵退场、人物恢复地面空闲，再松开并按 9 可重复召唤。数字 1—4 与快捷道具冲突，已适配道具请从背包选择“使用”。道场空格残心、空格＋2／3 近战切换教学、空格＋1／4 远程切换教学和 T 九十九教学保持；教学兼容不代表完整原生换武器或射击支持。

## 验证与限制

- 本地 v0.51 新增 8 项原生 CPU 回归、19 项 EXE 自检、588 次 EXE／源码布局比对通过（49 个补丁 × 12 组布局）。新回归与既有冻结证明分别记录，不声称全部历史检查重新运行。
- 公开源码另有 8 项门实例 CPU 检查，执行公开处理代码，原生动作查找、动作资源索引和设置动作调用使用显式 Win64 替身；不读取游戏代码或私有研究输入。这些检查不等同于本地使用私有已核对原生代码输入的 8 项回归，也不代替实测。Unicorn 2.1.4 仅用于开发检查，独立 EXE 不依赖它。
- 已反馈的信贵山门开启另获用户确认。私人游戏代码输入、原始日志和内存记录不分发，也不作为公开可移植 CI。
- **部分非关键道具使用仍未修复**。全部道具、词条、NPC、守护灵、地图和交互变体尚未逐一验证；动作显示仍可能固定大笑，吼叫额外元素叠加仍未完成。
- 最终公开 EXE 的新游戏进程首次接入尚未单独实测；离线检查不等同完整游戏验收。本版 CT 的 CE 内直接启用未测，Windows Beta 未作 Authenticode 签名。

Public packaging retains local 0.51's native behavior. Offline checks and the confirmed Shigisan door opening have distinct scope; they do not establish complete mission, item, save/load or cold first-enable coverage.

源提交、附件 SHA-256、组件和构建记录保存在源码包及发布页。Beta 4 和更早版本的标签、资产及历史记录保持原样。角色替换源自用户提供的 Bryanyora Character Change CT；工具不附带游戏程序、游戏资源或私人内存记录。
