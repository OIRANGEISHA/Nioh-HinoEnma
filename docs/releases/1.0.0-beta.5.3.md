# 1.0.0 Beta 5.3

适配 Steam《仁王 完全版》1.24.08。预发布测试版，2026-10-10。

## 本次改动

- 任务选择地图／据点中打开的装备、状态预览改用飞缘魔的模型、骨骼及原生待机，消除威廉身体与防具叠层。
- 镜头略拉远、目标略抬高，使用已接受的距离 740／高度 −45 取景，为头部留出空间并显示全身。
- 新显示实例自动绑定，地图重新载入时清除旧绑定；选择威廉或所属对象改变时保留原生回退。实际属性、装备加成与关卡角色的比例沿用原有计算。
- 保留 Beta 5.2 原有 60 处补丁，增加 10 处菜单兼容，共 70 处。武器固有元素、道具、梯子及交互修复和现有键位继续保留。

Beta 5.3 adds Hino-Enma's model, skeleton and native idle to the equipment/status preview opened from the mission-selection map or base, removes William body/armor overlays and adjusts full-body framing. The camera binds to each newly constructed display instance and falls back on selection/ownership changes. The unchanged 60-hook Beta 5.2 basis gains ten scoped preview hooks; gameplay stats, bonuses and controls are retained.

## 下载与使用

发布附件只有两个：

- `Nioh-HinoEnma-1.0.0-beta.5.3-windows-x64.exe`：直接运行的 Windows x64 工具，不需要 CE 或 Python。
- `Nioh-HinoEnma-1.0.0-beta.5.3-source.zip`：完整审核 Git 源码、匹配的 CT、双语说明、键位、构建及来源记录。

从旧版升级时先退出并重启游戏，停在 **NEW GAME／CONTINUE 主菜单**，运行本版 EXE 后继续到任务选择地图或载入关卡。切换角色需要返回主菜单再继续，重新生成后生效。每次重启游戏后再运行工具，同一游戏进程不要混用版本或 EXE／CT。

受支持的旧 55／59／60 处接入只读识别后要求重启，不迁移已有进程配置。

## 常用键位

| 按键 | 操作 |
| --- | --- |
| J／I／K | 踢腿／挥伞／撤步 |
| Shift | 恢复精力 |
| Q＋空格／Alt | 起飞／原有飞扑、俯冲 |
| 1 | 吸血及受支持的战后浓姬／雪女配对抓取 |
| 2（第一栏道具快捷位） | 使用兼容道具 |
| 5 | 地面与空中吼叫 |
| F6 | 净化附近常世，松开再按可重复 |
| 9 | 地面空闲、守护灵槽满时启动九十九并召唤守护灵攻击 |

**道具放到第一栏的 2 号快捷位**，其他位置仍使用飞缘魔技能或动作绑定；兼容道具也可从背包使用。九十九期间，守护灵退场且人物恢复地面空闲后，松开再按 9 可再次召唤。完整说明见 [键位文档](https://github.com/OIRANGEISHA/Nioh-HinoEnma/blob/v1.0.0-beta.5.3/docs/键位说明.md)。

## 验证与限制

- 临时游戏接入已由用户确认模型、原生待机、无威廉身体／防具叠层及目前取景。**最终公开 EXE 在全新游戏进程首次启用和重新载入尚未实测。** 本次确认覆盖地图／据点预览，不代表每个关卡内菜单或画面比例都已适配。
- 最终公开源码已通过 133 项回归（121 项保留及 12 项发布证据拒绝检查）和 25 项便携菜单测试，包含 2490 次字节比较、10005 次合成 CPU 比较与 12 组 ASLR 布局。公开源码 Debug、Release 各通过 28 项 C# 自检、840 次当前配置比较及 2088 次完整旧配置比较。源码／CT 通过 70 处接入、636 个唯一局部标签及 840 次命名空间比较；原有 60 处模板／重定位、720 个载荷及 720 个跳转与不可移动的 Beta 5.2 基础源码一致。
- 公开构建加入完整菜单接入安全依赖检查。实际离线结果及本地公开源码构建哈希见 [Beta 5.3 验证](https://github.com/OIRANGEISHA/Nioh-HinoEnma/blob/v1.0.0-beta.5.3/docs/validation-beta5.3.json)；精确源提交及最终 CI／下载附件哈希记录在源码 ZIP 的 `build-info/` 和发布正文。公开检查使用合成记录和显式 Win64 替身，不证明真实对象生命周期或完整原生游戏引擎执行。
- **部分非关键道具使用仍未修复。** 盐新增 Common 205／85 受击路径仍未在游戏内确认；战后抓取限于资源仍载入的浓姬／雪女，零生命目标不追加伤害、回血或复活。全部道具、词条、敌人、NPC、守护灵、地图和任务流程尚未逐一验证。
- 吼叫不追加元素，动作选单动画可能仍显示大笑。CT 在 CE 内直接启用尚未实测。Windows Beta 未作 Authenticode 签名。

The user-confirmed temporary preview trial is separate from the final public EXE, whose fresh-process enable/reload remains untested. Scope is the reported map/base preview. Portable tests use synthetic records and explicit Win64 stubs; they do not establish real object lifetimes or full game execution. Some non-critical item use remains unfixed. Compatible shortcuts remain in slot 2 on the first bar; digit 5 is roar, F6 purification and digit 9 native Living Weapon/guardian attack.

本次使用新的不可移动标签 `v1.0.0-beta.5.3` 和新的预发布记录，`latest=false`。旧标签、附件与历史记录保持不变。分发源码从精确审核的 Git 提交导出，源提交／树、Git 文件清单、附件大小与 SHA-256、实际发布者及构建来源记录见发布正文和源码包 `build-info/`。Release 只上传 EXE 与源码 ZIP，其他证明放在源码包或正文中。

角色替换源自用户提供的 Bryanyora CharacterChange CT，不附带游戏资产或私人内存记录。详见 [中文说明](https://github.com/OIRANGEISHA/Nioh-HinoEnma/blob/v1.0.0-beta.5.3/README.zh-CN.md)、[构建方法](https://github.com/OIRANGEISHA/Nioh-HinoEnma/blob/v1.0.0-beta.5.3/docs/BUILD.md)、[发布规范](https://github.com/OIRANGEISHA/Nioh-HinoEnma/blob/v1.0.0-beta.5.3/DEVELOPMENT_RELEASE_STANDARD.md) 和 [来源说明](https://github.com/OIRANGEISHA/Nioh-HinoEnma/blob/v1.0.0-beta.5.3/NOTICE.md)。
