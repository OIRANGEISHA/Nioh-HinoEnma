# 1.0.0 Beta 5.3.1

Steam《仁王 完全版》1.24.08，预发布测试版，2026-10-10。用户已授权本次新的 Beta 5.3.1 发布；完成源码、标签及下载附件校验后发布为 Pre-release，`latest=false`。

- 补上地图／据点装备、状态预览的飞缘魔周身常世雾气。
- 修复返回主菜单再继续后镜头恢复原样的问题，继续采用已确认的距离 740／高度 −45。
- 保留飞缘魔原生待机、去除威廉身体／装备叠层，以及之前的属性、武器元素、道具、梯子和交互兼容。
- 71 处接入：原有 68 处保留，替换两处镜头并新增一处雾气接入。用户已确认临时修订在重开状态页及主菜单重载后正常。

Release 附件仅有两个：

- `Nioh-HinoEnma-1.0.0-beta.5.3.1-windows-x64.exe`：直接运行的 Windows x64 工具，不需要 CE、Python 或源码包。
- `Nioh-HinoEnma-1.0.0-beta.5.3.1-source.zip`：从精确审核 Git 提交导出的完整源码、匹配 CT、说明、键位及构建来源记录。

升级后重启游戏，停在 NEW GAME／CONTINUE 主菜单，运行 EXE 再继续。旧版接入只读识别后要求重启，不迁移旧进程。

键位沿用原设置：J 踢腿、I 挥伞、K 撤步、Shift 回精力、Q＋空格起飞、Alt 飞扑／俯冲、1 吸血、5 吼叫、F6 净化常世、9 九十九与守护灵攻击。兼容道具放到**第一栏 2 号快捷位**，也可从背包使用。详见 [键位说明](https://github.com/OIRANGEISHA/Nioh-HinoEnma/blob/v1.0.0-beta.5.3.1/docs/键位说明.md)。

**部分非关键道具仍未修复**，全部场景与招式未逐一验证；菜单修复覆盖已反馈的地图／据点预览。打包后独立 EXE 在新进程首次启用仍待游戏确认，CT 在 CE 内直接启用未实测。

本地源码离线验证：134 项源码回归、41 项菜单测试（4280 字节／15880 合成 CPU 比较、12 布局）。Debug 与 Release 各通过 28 项 C# 自检、852 当前与 2928 旧配置载荷比较。原 60 处基础载荷和跳转保持一致。结果见 [验证记录](https://github.com/OIRANGEISHA/Nioh-HinoEnma/blob/v1.0.0-beta.5.3.1/docs/validation-beta5.3.1.json)。这些本地结果及 EXE 哈希保留原来源，不作为最终 CI 构建或下载附件的校验结果。

本次采用新不可移动标签 `v1.0.0-beta.5.3.1` 和新的预发布记录，既有 Beta 5.3 及更早标签、附件和历史记录保持不变。发布源码由 `tools/package.py` 从精确审核 Git 提交导出；源提交／树、逐文件清单、最终构建来源、附件大小及 SHA-256 记录在源码 ZIP 的 `build-info/` 和发布正文中。实际发布者及下载附件读回通过验证后才完成发布；生成的 CI 证明在正文中链接，不增加附件。源码不含游戏资源、内存转储或开发依赖二进制。本版没有 Windows Authenticode 签名。
