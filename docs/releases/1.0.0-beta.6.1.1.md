# Beta 6.1.1 — 道具效果与受击兼容修复

2026-10-15 · `1.0.0-beta.6.1.1` · 本地打包

- **风箭符、克金符**：修复只有动作／特效、没有实际符咒飞出或扣除次数的问题。
- **道具受击恢复**：修复已支持公共使用动作在受击后误选飞缘魔撑伞嘲讽、飞起或吼叫的问题，保留原生伤害、精力消耗和受击判定。
- **连续施法**：补上移动后再使用克金等符咒时的公共动作查找，已测试连续使用及石头投掷。
- **护灵招来符、污泥罐**：恢复从背包使用后的守护灵召唤攻击、罐子投放与污泥效果，以及原生次数／数量扣除。

兼容道具从背包或**第一栏数字 2**使用；其余快捷位继续保留技能。常用键仍为 **1 吸血、5 地面／空中吼叫、9 九十九与守护灵、F6 净化常世**。完整键位见随包《键位说明.md》。

成长、装备、修正 LV、九十九、附魔、预览和交互兼容沿用现有版本。运行本版 EXE 前完整退出并重启游戏，在 NEW GAME／CONTINUE 主菜单启用，然后继续游戏；每次游戏重启后需重新运行工具。EXE 无需 CE 或 Python。

这批修订已热接入并获用户实测确认；新 EXE 单独验证版本、源代码、重定位后的补丁和自检结果，尚未完整重启实机验收。原始实测报告保留，离线检查不代表所有道具、敌人和受击分支已经实测。部分非关键道具及其他同名定义仍未修复或验证。

本地主要产物为独立 Windows x64 EXE 和完整源码 ZIP，旁附使用说明、键位、清单和 SHA-256；CT 位于源码包内。
