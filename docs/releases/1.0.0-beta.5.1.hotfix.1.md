# 1.0.0 Beta 5.1 Hotfix 1

适配 Steam《仁王 完全版》1.24.08。预发布测试版，2026-10-09。

## 本次修复

- 修复已反馈的“比睿山的魔物”地下往地面梯子上爬中途掉落，以及逐步瞬移、其他梯子离梯高度过高。
- 下一段攀爬动作尚未成为当前动作时，原流程仍按飞缘魔的 1.8 倍动作比例预计算位移；本版同时核对当前与待切换的 Common 梯子动作，补齐位移采样和对应渲染层。
- 新增四处限定当前玩家与真实梯子资源的接入，原有 55 处补丁保持不变，完整配置为 59 处。保留角色本身模型比例、Boss 基础数值叠加成长和装备加成，以及此前招式、道具和交互功能。
- 不新增键位：使用游戏交互键进入梯子，W 上爬、S 下爬。

This Hotfix fixes the reported Mount Hiei underground ladder fall, per-step teleporting and excessive ladder-exit height. The next climbing clip was still sampled at Hino-Enma's 1.8 motion scale before it became the current action. Four scoped hooks cover current/pending Common-ladder samples and the matching rendered layer. The actor's model scale and all 55 prior hooks are preserved; the complete profile has 59 hooks.

## 下载与使用

Release 仅保留两个附件：

- `Nioh-HinoEnma-1.0.0-beta.5.1.hotfix.1-windows-x64.exe`：独立 Windows x64 工具，不需要 CE 或 Python。
- `Nioh-HinoEnma-1.0.0-beta.5.1.hotfix.1-source.zip`：完整公开源码、CT 源码、构建方法、使用和键位说明及构建记录。

从旧版升级时先退出游戏。从 Steam 重新启动，停在 **NEW GAME / CONTINUE 主菜单**，运行本版 EXE 后载入关卡。角色切换需要返回主菜单再载入；每次重启游戏后再运行工具。同一进程不要混用不同版本或 EXE／CT。

## 键位

以下沿用已测试的游戏设置；数字键指主键盘数字行。

| 按键 | 操作 |
| --- | --- |
| W / A / S / D | 移动 |
| J | 踢腿 |
| I | 挥伞 |
| K | 撤步 / 闪避 |
| Shift | 恢复精力 |
| Q + 空格 | 起飞 |
| Alt | 飞扑 / 俯冲 |
| 1 | 吸血；包括受支持的战后浓姬／雪女抓取动画 |
| 2（第一栏道具快捷位） | 使用兼容道具；当前唯一支持的道具快捷位 |
| 5 | 地面和空中吼叫 |
| F6 | 净化附近常世；松开再按可再次触发 |
| 9 | 地面空闲、守护灵槽满时启动九十九并召唤守护灵攻击 |
| 游戏交互键，随后 W / S | 进入梯子后上爬 / 下爬 |

九十九期间，守护灵退场且人物恢复地面空闲后，松开再按 9 可重复召唤。**快捷道具放到第一栏的 2 号快捷位**；其他快捷位置继续触发飞缘魔技能或动作。兼容道具也可从背包使用。道场空格残心、空格＋2／3 近战切换教学、空格＋1／4 远程切换教学和 T 九十九教学保持。

## 验证与限制

- 第二轮临时梯子修订获用户确认“正常了”，覆盖本次要求的上下爬、逐步位移和离梯高度；只读记录观察到两架不同梯子及其上下爬、离梯过程。其他梯子、攀爬受击中断和所有地图尚未全面实测。
- 本地整合检查通过 50 项测试、693 次 CPU 状态比较，以及原 55 处补丁在 12 种布局下的 660 次原样比较。本地测试 EXE 通过 22 项离线自检和 708 次载荷比较。它们不是本次公开构建结果；公开源码、Debug／Release 检查实际结果见 [Hotfix 验证](https://github.com/OIRANGEISHA/Nioh-HinoEnma/blob/v1.0.0-beta.5.1.hotfix.1/docs/validation-beta5.1-hotfix1.json)。
- 公开 Debug 和 Release 各通过 23 项 C# 自检、708 次载荷比较（59 处 × 12 布局）。公开 CPU 测试共 93 项通过，其中新增梯子 44 项、693 次 CPU 状态比较；源码／CT 检查通过 540 个唯一局部标签和 708 次比较。完整 59 处公开载荷与已实测整合版本在 12 布局下的 708 次比较全部一致。
- 最终公开 EXE 在全新游戏进程首次接入尚未进行游戏实测。便携检查使用合成记录或显式替身，不证明渲染动画、完整原生游戏事件、存取档或所有任务切换通过；私有原生代码与原始内存记录不分发。
- **部分非关键道具使用仍未修复**。保留 Beta 5.1 已有范围：战后抓取限于已反馈的浓姬／雪女且需要资源仍载入；零生命目标不追加伤害、回血或复活；盐新增 Common 205／85 受击路径仍限 CPU 覆盖；吼叫不叠加第二元素。全部道具、装备词条、NPC、守护灵、地图及交互变体尚未逐一验证。
- 动作可能固定显示大笑，实际切换 Boss 武器和完整原生射击未接入。直接在 CE 中启用 CT 尚未实测，推荐 EXE；Windows Beta 未作 Authenticode 签名。

The successful ladder gameplay confirmation used the second temporary revision, with two ladder objects observed read-only. Local private regressions, the earlier local test EXE and this public build have separate evidence records. Final public EXE cold first-enable, all ladders and interruption variants remain unverified. Some non-critical item use remains unfixed. Item shortcuts support only slot 2 on the first bar; other slots retain Boss skills/moves.
