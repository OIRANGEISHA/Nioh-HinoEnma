# Beta5.6.3 — 750级成长与修正LV兼容

2026-10-13 · GitHub Pre-release

- 普通等级按 `1 + floor(4524 × 等级 / 750)` 映射到飞缘魔原生成长档位。0是数学起点，实际存档等级1—750；400级2413档、401级2419档、750级4525档。
- 从401级起立即采用Boss基础生命×2、主攻击×1.2，随后叠加玩家成长、装备及修正LV；精力、防御继续使用原生曲线。保留自身已有的更高原生档位。
- 补回选中近战武器的固定攻击收益，包括攻击修正LV。体力、攻击、防御、幸运四类修正沿用原生收益与共享1000上限；不参与普通等级映射或401级门槛。
- 保留Beta5.6.2的99武器、守护灵、固有附魔、菜单预览、梯子、交互及无间狱修复。只改变属性叠加载荷，其他81处运行载荷不变。

本次成长载荷已在运行中的750级角色上接入，用户刷新装备后确认移动与J/I正常。该次装备下生命上限301211、精力425、防御21552，五个攻击通道各为主攻击31876加固定攻击209，合计32085。这些是实测值，不是硬编码目标。

离线覆盖全部750个有效等级、400/401边界、四类修正、重复刷新、武器槽与ABI保留。另有私有原生函数750等级与25组Focus分配审计，游戏代码及内存快照不包含在源码包中。打包验证另记录248项回归、Debug/Release各30项自检、984次当前载荷和7536次历史载荷比较；具体结果见随包验证记录。

此版本EXE尚未进行完整重启后的独立实机测试；非零体力/防御/幸运修正的实机分配，以及实际跨400/401升级未重测。新EXE未实机验收，不能将热接入确认视为新EXE冷启动测试。

已知限制：忍术道具目前无法使用，部分非关键道具尚未修复；下载存档的非标准装备未全面覆盖。道具可从背包或第一栏数字2快捷位使用，其余快捷位保留飞缘魔技能。吼叫原有效果继续受保护。

安装：完整退出并重启游戏，停在NEW GAME / CONTINUE主菜单，运行本版EXE后继续游戏。每次游戏重启后需重新运行工具。EXE无需CE或Python；CT是可选方式，不与EXE同时启用。数字1吸血、5吼叫、9九十九、F6净化常世，完整键位见docs/键位说明.md。
