# 1.0.0 Beta 4

适配 Steam《仁王 完全版》1.24.08，整合本地 v0.50。预发布测试版，2026-10-09。

## 下载与使用

Release 只提供两个附件：

- `Nioh-HinoEnma-1.0.0-beta.4-windows-x64.exe`：直接运行的 Windows x64 工具，不需要 CE 或 Python。
- `Nioh-HinoEnma-1.0.0-beta.4-source.zip`：完整公开源码、构建方法、键位说明及构建记录。

从 Steam 启动游戏，停在 **NEW GAME / CONTINUE 主菜单**，运行 EXE 后载入关卡。角色切换选项也需要返回主菜单再载入。每次重新启动游戏后再运行工具。

## 本版修复

- 倒地誾千代的救助：补上公共救助动作入口，恢复和交互结束由游戏原生流程处理。用户已确认能救起，结束后移动、J/I 和数字 5 正常。
- NPC 交谈、门闩门开启；小妖怪动作提示选择“交给我吧”后已确认可以继续。
- 路标符的投放动作、地面路标、罗盘标记及重复使用。
- 吸血击败敌方飞缘魔后的玩家保留、视角和关卡继续；已确认重新载入及进入新关卡正常。

继承已测试的双向梯子、温泉、道祖神护符、神篱碎片、部分恢复/Buff 道具、守护灵召回与死亡刀冢拾回，以及生命、精力、攻击、防御的等级映射和 Boss 基础值加成。

## 常用键位

下表沿用当前已测试的游戏键位设置；若更改游戏按键配置，对应操作可能不同。数字键指主键盘数字键。

| 按键 | 操作 |
| --- | --- |
| W / A / S / D | 移动 |
| J | 踢腿攻击，连续按可连踢 |
| I | 挥伞攻击，连续按可连击 |
| K | 撤步 / 闪避 |
| Shift | 恢复精力 |
| Q + 空格 | 起飞 |
| Alt | 飞扑 / 俯冲 |
| 1 | 吸血 |
| 5 | 地面和空中吼叫 |
| F6 | 净化附近常世；长按一次，松开再按可再次触发 |
| 9 | 地面空闲、守护灵槽满时启动九十九并召唤守护灵攻击 |
| 游戏交互键，随后 W / S | 进入梯子后向上 / 向下攀爬 |

九十九期间，等守护灵退场、人物恢复地面空闲，再松开并按 9 可重复召唤。数字 1—4 与快捷道具冲突，已适配道具请从背包选择“使用”。

道场兼容：攻击后按空格触发残心教学；空格 + 2 / 3 补近战武器切换教学，空格 + 1 / 4 补远程武器切换教学；T 完成九十九教学并保留原招式。真实九十九使用数字 9。武器切换教学兼容不代表飞缘魔已实现威廉的完整换武器或射击动作。

## 已知限制

- **部分非关键道具使用仍未修复**；未逐一适配全部道具、特殊词条和使用动作。
- 快捷道具键与 Boss 技能有冲突，背包使用是当前已适配道具的使用方式。
- 动作选单仍可能固定显示大笑；吼叫保留原有异常效果，额外元素叠加尚未完成。
- 其他 NPC、重复救助、全部关卡、交互变体与守护灵组合尚未全部测试。
- 本版 CT 的 CE 内直接启用尚未实测；Release 推荐独立 EXE。

## 验证与来源

本地 v0.50 新增 8 项离线回归通过，誾千代救助实测通过。公开 Debug 和 Release 构建分别通过 19 项 EXE 自检、12 组地址布局下的 588 次源码与补丁对照；49 个补丁与实测 v0.50 相同。版本展示和打包变化不等于新的完整游戏验收。

构建记录、组件说明和文件校验保存在源码包内，EXE 与源码包的 SHA-256 也列于发布页。角色替换机制源自用户提供的 Bryanyora Character Change CT，保留原作者署名；工具不附带游戏程序、游戏资源或私人内存记录。
