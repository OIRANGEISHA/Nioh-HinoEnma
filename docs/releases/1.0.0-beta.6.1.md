# Beta 6.1 — 风箭符、克金符与火炎龙术兼容

2026-10-13 · `1.0.0-beta.6.1` · GitHub Pre-release

修复以下三项从背包使用无反应、次数不扣除的问题：

- **风箭符**：恢复原生施法、风箭效果和术次数消耗。
- **克金符**：恢复原生施法、命中效果和术次数消耗，区分公共施法动作与飞缘魔私有同编号动作。
- **火炎龙术卷轴**：恢复原生火龙效果、术次数消耗及收招流程。

用户已确认三项正常，包括次数扣除、效果和使用后的移动、J／I／数字 5。修订只覆盖这次验证的三项定义；其原生动作、动画与主辅事件保持一致。只读记录确认施法和收招恢复，数量和实际效果的结论来自用户实测。

保留 Beta 6 的道具修复和全部原有键位。兼容道具从背包或**第一栏数字 2**使用；其他快捷位继续保留飞缘魔技能。常用键仍为 **1 吸血、5 地面／空中吼叫、9 九十九与守护灵、F6 净化常世**，完整说明见随包《键位说明.md》。

成长规则不变：普通等级 0—750 线性映射到 1—4525 档，401 级起 Boss 基础生命 ×2、主攻击 ×1.2，再叠加原生成长、装备和修正 LV。精力、防御使用原生曲线，并保留已有的更高原生档位。九十九、附魔、菜单预览、梯子和交互兼容继续保留。

这次实测针对运行中的修订；新 Beta 6.1 EXE 单独进行离线验证，尚未完成该 EXE 的完整重启实测。完整回归、编译载荷、实测身份、CT 三方比较和源码包成员校验的结果见随包验证记录。此前版本的全部场景未在本轮重新测试。

本版还调整启动器的完整补丁读取上限，以容纳新增施法后的较大载荷；继续分块读取并拒绝不完整结果，确保能够核对完整补丁。此项启动器修正与运行中的道具实测分别验证。

**已知限制：** 其他同名变体、其他术和部分非关键道具尚未修复或验证；不宣称所有道具、忍术或阴阳术均可使用。施法受击打断及所有战斗场景未全面验证。

GitHub Release 仅提供独立 Windows x64 EXE 和最终提交的完整源码 ZIP。使用说明、键位、CT 与构建、校验记录包含在源码包内，SHA-256 写在下方。原本地包与历史版本文件保留。运行前完整重启游戏，在 NEW GAME／CONTINUE 主菜单启用工具后继续，每次游戏重启后需重新运行工具。EXE 无需 CE 或 Python。
