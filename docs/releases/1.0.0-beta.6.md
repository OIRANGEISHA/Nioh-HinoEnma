# Beta 6 — 道具与施法兼容

2026-10-13 · `1.0.0-beta.6` · GitHub Pre-release

本版整合以下用户已实测通过的修订：

- 切腹短刀：从背包使用后正常死亡、回到神社复活，复活后移动与 J／I 正常。
- 粪球、高贵的粪球、天狗的团扇：恢复投掷／使用动作、数量消耗和实际效果。
- 石头、火药弹、焙烙弹、焚火油壶：恢复投掷、命中／爆炸／燃烧效果及数量消耗。
- 御箭护符与本次测试的迟钝符：修复公共施法动作 41／42 与飞缘魔私有同编号动作冲突；使用原生施法、增益／投射物和物品／术次数消耗流程。迟钝符仅覆盖已测试定义 `4998`，其他同名定义未纳入。

道具效果、数量或术次数、御箭增益、迟钝命中减速及使用后移动、J／I／数字 5 的结果由用户确认。只读记录另确认两符分别进入公共动作 41／42、请求清除并恢复待机；记录本身不测量库存、增益或敌方减速。各阶段原始实测记录见 [切腹短刀](../harakiri-gameplay.json)、[粪球与团扇](../dung-fan-gameplay.json)、[四种投掷道具](../four-throwables-gameplay.json)及[御箭与迟钝符](../arrow-sloth-gameplay.json)。

成长规则继续沿用 Beta 5.6.3：普通等级按 `1 + floor(4524 × 等级 / 750)` 映射到 1—4525 档，0 为数学起点；400 级为 2413 档、401 级为 2419 档、750 级为 4525 档。从 401 级起立即采用 Boss 基础生命 ×2、主攻击 ×1.2，再叠加玩家成长、装备和修正 LV；精力、防御使用原生曲线，并保留自身已有的更高原生档位。体力、攻击、防御、幸运修正继续按原生收益及共享 1000 点上限计算，不参与普通等级映射或 401 级门槛。

本次保留九十九、守护灵、武器固有附魔、菜单预览、梯子、交互和无间狱等既有修复。键位不变：**1 吸血、5 吼叫、9 九十九、F6 净化常世**；兼容道具从背包或**第一栏数字 2**使用，其他快捷位继续保留飞缘魔技能。完整说明见[键位文档](../键位说明.md)。

本批修订已在运行中的游戏里实测通过；新 Beta 6 EXE 仅完成离线检查，尚未经过完整重启后的独立实机测试。离线回归、载荷身份、CT 与源码打包核对的实际结果见随包验证记录。历史实测文件保留记录时的发布状态，不代表当时已包含 Beta 6 整合。此前版本的全部场景未在本轮重新测试。

Debug／Release 各通过 30 项离线自检、984 次当前载荷比较（12 种布局）及 7536 次历史比较（108 种布局）。984 次与实测修订的身份比较一致，75 处其他载荷的 900 次比较不变；CT 三方 984 次比较、1172 个标签及 26 项拒绝条件检查通过。完整回归 291／291 通过，失败、错误和跳过均为 0，用时 126.278 秒，受检源码在运行前后保持不变。新增回归覆盖 82 处载荷 ×12 种布局的编译地址修复，以及旧代码区间遗漏时的拒绝检查。

构建时还补齐了新增道具辅助代码的重定位区间，避免 EXE 在不同分配地址下漏修地址；汇编载荷与实测修订保持一致。源码换行规范化后重新编译并通过载荷核对，最终 Release EXE 大小为 873472 字节，SHA-256 为 `6494e231a40e46fb7ef03ac4e711e391b8b05aba0efeb791332b6262d692b455`。

已知限制：其他迟钝符定义、其他术及部分非关键道具尚未修复或验证，不宣称所有道具、忍术或阴阳术均可用；施法受击打断、非标准装备及所有场景未全面验证。

按用户后续授权发布 GitHub，附件仅独立 Windows x64 EXE 和最终提交的完整源码 ZIP；说明、键位、CT 和验证记录在源码包中，SHA-256 见发布页。沿用原本地 EXE，保留原本地包、历史标签和附件。使用前完整重启游戏，在 NEW GAME／CONTINUE 主菜单启用工具后继续；每次游戏重启后需重新运行工具。EXE 无需 CE 或 Python。
