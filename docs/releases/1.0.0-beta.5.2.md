# 1.0.0 Beta 5.2

适配 Steam《仁王 完全版》1.24.08。预发布测试版，2026-10-10。

## 本次修复

- 将所选近战武器的火、水、雷、风、土固有元素传递到受支持的踢腿、挥伞、冲撞、麻针与吸血命中。缠属性护符和九十九的临时附魔继续优先。
- 第二轮临时修订已由用户确认：装备雷切“赋予雷属性 +8”，不用护符或九十九，上述五类招式都有雷效果，移动、攻击、麻针与吸血正常。
- 麻针原有麻痹及吼叫原有效果保留，吼叫不追加元素。普通身体攻击采用原生主附魔通道的优先级，不承诺身体攻击另有独立的麻痹叠加。
- 保留 Boss 基础数值叠加成长、装备和所选武器加成的计算；保留此前梯子、战后浓姬／雪女抓取、道具和交互修复。更新四处接入并新增一处，完整配置为 60 处。
- 启动工具扩展完整旧 55／59 处配置识别，只读逐项核对完整入口和载荷；损坏或未知配置仍拒绝接入。新安装另检查可执行代码及三页可写、不可执行数据，保留事务与回滚保护；不将旧配置识别描述为已实测其实时内存页保护。

“赋予某属性 +数值”提供元素；“给予某属性伤害 +百分比”增强已有对应元素伤害，百分比本身不会产生附魔。重新装备所选武器并关闭菜单，或重新载入角色，可触发固有元素的正常刷新。

Beta 5.2 passes the selected melee weapon's native innate element to supported kicks, umbrella attacks, body charge, needles and life drain. Raikiri's “Imbue Lightning +8” is user-confirmed on all five reported attacks. Temporary talismans and Living Weapon keep priority. Needle paralysis and the roar's effects are retained; the roar receives no added element. Ordinary body attacks use native primary enchantment priority, without claiming an independent second paralysis channel.

## 下载与使用

Release 仅上传两个附件：

- `Nioh-HinoEnma-1.0.0-beta.5.2-windows-x64.exe`：直接运行的 Windows x64 工具，不需要 CE 或 Python。
- `Nioh-HinoEnma-1.0.0-beta.5.2-source.zip`：完整公开源码、匹配的 CT、构建方法、双语说明、键位及构建记录。

从旧版升级时先退出游戏。从 Steam 重新启动，停在 **NEW GAME / CONTINUE 主菜单**，运行本版 EXE 后载入关卡。角色切换需要返回主菜单再载入；每次重启游戏后再运行工具。同一游戏进程不要混用不同版本或 EXE／CT。

## 键位

以下沿用已测试的游戏键位；数字键指主键盘数字行。

| 按键 | 操作 |
| --- | --- |
| W / A / S / D | 移动 |
| J | 踢腿 |
| I | 挥伞 |
| K | 撤步 / 闪避 |
| Shift | 恢复精力 |
| Q + 空格 | 起飞 |
| Alt | 原有飞扑 / 俯冲 |
| 1 | 吸血；包括受支持的战后浓姬／雪女完整抓取动画 |
| 2（第一栏道具快捷位） | 使用兼容道具；当前唯一支持的道具快捷位 |
| 5 | 地面与空中吼叫 |
| F6 | 净化附近常世；松开再按可再次触发 |
| 9 | 地面空闲、守护灵槽满时启动九十九并召唤守护灵攻击 |
| 游戏交互键，随后 W / S | 进入梯子后上爬 / 下爬 |

九十九期间，等守护灵退场、人物恢复地面空闲，再松开并按 9 可重复召唤。**快捷道具放到第一栏的 2 号快捷位**；其他快捷位继续触发飞缘魔技能或动作，目前不改这些绑定。兼容道具也可从背包使用。

道场空格兼容残心／净化；空格＋2／3 兼容近战切换教学，空格＋1／4 兼容远程切换教学；T 完成已反馈的九十九教学并保留原有攻击。教学兼容不代表实际 Boss 武器切换或完整原生射击已接入。

## 验证与限制

- 雷切的游戏确认来自第二轮五处临时接入，完整公开 EXE 没有进行新进程首次接入的游戏测试。该实测不等于所有元素、词条、空中变体、具体伤害／异常力度或全部任务流程都已验证。
- 本地修订 2 EXE 通过 23 项离线自检和 720 次载荷比较（60 处 × 12 布局）；私有原生回归通过 20 项测试、959 次 CPU 状态比较，以及 55 处未改变载荷在三种布局下的 165 次比较。公开 Beta 5.2 加入启动工具检查，其实际构建及公开 CPU 结果单独记录在 [Beta 5.2 验证](https://github.com/OIRANGEISHA/Nioh-HinoEnma/blob/v1.0.0-beta.5.2/docs/validation-beta5.2.json)。
- 公开 Debug 和 Release 各通过 26 项自检、720 次当前配置比较和 1368 次完整旧配置比较（55／59 处 × 12 布局）。源码／CT 检查通过 60 处接入、555 个唯一局部标签、720 次命名空间比较及 6 项拒绝条件检查。这些检查不访问游戏，不证明新进程首次接入。
- 公开便携检查使用合成记录和显式 Win64 替身，不执行完整游戏伤害／事件引擎或背包提交。私有原生代码、游戏资源与原始运行记录不包含在公开源码或 CI 中。
- **部分非关键道具使用仍未修复**。保持此前实测边界：盐新增 Common 205／85 中断路径仍未在游戏内确认；梯子结果限于已反馈位置；战后抓取限于仍载入所需资源的浓姬／雪女，零生命目标不追加伤害、回血或复活。所有道具、NPC、守护灵、地图和交互变体尚未逐一验证。
- 动作动画可能固定为大笑；吼叫不追加元素。CT 在 CE 内直接启用尚未实测，推荐 EXE。Windows Beta 未作 Authenticode 签名。

Local native-code regressions, the local revision-2 EXE and this public build have separate evidence records. The user-confirmed live trial does not establish final-public-EXE cold first-enable, all elements or exact damage/status strength. Some non-critical item use remains unfixed. Item shortcuts support only slot 2 on the first bar; other slots retain Boss skills and moves.
