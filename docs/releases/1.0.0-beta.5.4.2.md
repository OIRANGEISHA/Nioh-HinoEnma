# 1.0.0 Beta 5.4.2

Steam《仁王 完全版》1.24.08，2026-10-11，文件版本 1.0.0.69。用户已授权本版源码推送及独立 GitHub Pre-release，附件为 Windows x64 EXE 和完整源码 ZIP。

九尾妖狐倒地后，Beta 5.4.1 的大蛇处理不会进入九尾独立分支，重攻击仍为旋转。本版绑定原生 `4026/1210 → 1273/1211` 玩家链与 `1274/31010` 目标链，补齐主辅动画及主辅事件，并保护起手、待配对期间的 query86。目标第 510 帧 local77 保留原生伤害和死亡处理，剧情由游戏执行。

场景候选已完成原生击杀、剧情继续和控制恢复。精确 Release EXE 随后通过完整退出并重启游戏、主菜单启用与九尾最终处决复测，81 处入口及完整载荷均与正式版一致，未接入临时补丁或诊断钩子。只读核对确认原生死亡、配对与锁定清除、玩家返回待机、处决阶段归零；用户确认“能正常处决并让剧情继续”，随后另行确认“已恢复正常操作”。本次在最终采样开始前已按重攻击，正式 EXE 的只读证据限于处决后的结束状态；逐帧动作时钟仍属于之前的场景候选。

上述正式 Release EXE 的 SHA-256 为 `dc771492d5e4a6521b3d36ac287c4a644c7de39a926a7b5e39c1ff983d984e20`。详见[精确验证记录](../validation-beta5.4.2.json)和[九尾调查记录](../ninetails-execution-investigation.md)。实机证据与离线证明分别记录；静态代码包含 character_dead 回调入口，但现场标志未满足其条件，本次没有把该回调描述为已执行。

仍为 81 处入口。八处共享载荷增加双 Boss 路由，原有大蛇处理体完整保留，其余 73 处载荷一致。九尾使用独立 512 字节绑定；分配大小为 0x51000，九个数据页可写且不可执行。八种历史安装身份 55/59/60/70/71/71/80/81 只读识别后要求重启。

203 项源码回归全部通过，其中九尾 24 项、大蛇 34 项。四项来源证明覆盖原 Beta 5.2、菜单、大蛇和九尾。Debug/Release 各通过 29 项自检、12 布局 972 次当前载荷核对和 96 布局 6564 次历史载荷核对；九尾证明保留 73 处载荷与入口各 876 次比较、八个原有大蛇处理体。数字描述离线覆盖，不代表实机战斗次数。

升级后完整重启游戏，在 NEW GAME/CONTINUE 主菜单启用本版。九尾或大蛇最后目标倒地后，锁定并靠近处决位置，轻按一次原重攻击键（本次设置为 T），等待完整动作、剧情与控制恢复。其他情况下仍使用飞缘魔旋转攻击。

本次九尾覆盖已反馈的 ready3174 场景和 key1 已加载武器资源；其他武器包、难度变体与联机处决没有逐一验证。Beta 5.4.2 未重打大蛇整场，原代码保留及 CPU 路由核对独立于 Beta 5.4.1 的历史实机成功。新角色代次会清除旧绑定，此次被拒绝的重攻击查找先回退，下次查找才重新发现。CT 在 CE 内直接启用尚未实测。

已知问题：用户反馈无间狱坐船会导致游戏闪退。此问题在 Beta 5.4.2 中尚未修复，后续单独处理；本次未宣称已定位其原因。

另一项已知问题：无间狱无法前往下一层，交互进度满后没有反应。此问题尚未修复，后续单独处理。
