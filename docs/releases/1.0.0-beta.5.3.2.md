# 1.0.0 Beta 5.3.2

Steam《仁王 完全版》1.24.08，预发布测试版，2026-10-11。

- 修复完整重启游戏、在主菜单启用工具后，直接进入地图／据点的装备、状态预览又显示威廉的问题。
- 等待原生地图加载条件满足后再计算角色资源超时；临时缺少资源管理器时可在当前生成周期重试。保留一次预载请求、有限等待和原生回退。
- 共 71 处接入，只更新资源就绪这一处，其余 70 处及原有游玩功能保持一致。飞缘魔原生待机、周身常世雾气和镜头距离 740／高度 −45 均保留。

Release 附件仅有两个：

- `Nioh-HinoEnma-1.0.0-beta.5.3.2-windows-x64.exe`：独立 Windows x64 工具，不需要 CE、Python 或源码包。
- `Nioh-HinoEnma-1.0.0-beta.5.3.2-source.zip`：精确发布提交的完整源码、匹配 CT、说明、键位和构建来源记录。

升级后先重启游戏，停在 NEW GAME／CONTINUE 主菜单，运行 EXE 并启用飞缘魔，再继续游戏。每次重启游戏后都需重新运行并启用；旧版接入只读识别后要求重启，不迁移旧进程。

常用键位：J 踢腿、I 挥伞、K 撤步、Shift 回精力、Q＋空格起飞、Alt 飞扑／俯冲、1 吸血、5 吼叫、F6 净化常世、9 九十九与守护灵攻击。兼容道具放在**第一栏 2 号快捷位**，也可从背包使用。详见 [键位说明](https://github.com/OIRANGEISHA/Nioh-HinoEnma/blob/v1.0.0-beta.5.3.2/docs/键位说明.md)。

修订测试 EXE 已通过完整游戏进程重启，并在未先进入关卡时直接打开据点状态页；用户确认模型、待机、镜头和雾气正常。记录为原生加载等待 498 帧、资源等待 34 帧、预载一次、无回退。正式发布 EXE 另行构建，源码中的 71 处补丁及原生目标与已实测修订一致；不将测试 EXE 的哈希写成最终 CI 附件哈希。

本地离线校验通过 134 项源码回归、41 项保留菜单测试（4280 字节比较／15880 合成 CPU 比较）以及 18 项重启等待测试（19892 合成 CPU 帧、852 重定位比较、840 其余补丁保持比较）。Debug 与 Release 各通过 28 项 C# 自检、852 当前配置和 3780 旧配置载荷比较。原 60 处 Beta 5.2 基础载荷、跳转和修正点保持一致。见 [验证记录](https://github.com/OIRANGEISHA/Nioh-HinoEnma/blob/v1.0.0-beta.5.3.2/docs/validation-beta5.3.2.json)。最终 CI 构建、源提交／树、逐文件清单及下载附件大小／SHA-256 另记于源码 ZIP 的 `build-info/` 与本发布正文。

**部分非关键道具使用仍未修复**，全部场景、物件、招式和不同宽高比未逐一测试；菜单修复覆盖已反馈的地图／据点预览。CT 在 CE 内直接启用尚未实测，Windows EXE 未作 Authenticode 签名。

本次采用新的不可移动标签 `v1.0.0-beta.5.3.2` 和新的 Pre-release，`latest=false`。既有标签、Release 附件和历史验证记录保持不变。源码不含游戏程序／资源、内存转储或开发依赖二进制；生成的 CI 来源证明在发布正文中链接，不增加附件。

Beta 5.3.2 fixes the equipment/status preview reverting to William after a complete game restart. Native loading gates have a separate bounded wait; temporary resource-manager absence can retry without duplicate preloads. The test EXE passed a cold restart and direct base-menu visit with normal model, idle, framing and mist. The public EXE is built separately and checked against the same 71 hook payloads. Exactly two assets are published: the standalone EXE and complete Git-source ZIP.
