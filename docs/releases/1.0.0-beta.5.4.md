# 1.0.0 Beta 5.4 本地测试包

Steam《仁王 完全版》1.24.08，2026-10-11，文件版本 1.0.0.67。

本版接入八岐大蛇最后一击的原生重攻击、主辅动画、事件和配对动作链，并保护处决中零长度及 NaN/Infinity 几何查询。击杀后原生配对引用清空的阶段也有独立条件保护。新增 9 处接入，共 80 处；原 Beta 5.3.2 的 71 处载荷保持一致。

场景绑定的第五版加第二版查询保护，已由用户确认完整播放后续动作与过场并恢复控制。只读证据为原生蛇头死亡计数 8、目标生命 0、私有阶段 0、待机恢复计数 1。正式包增加了当前实例动态绑定，是另一项实现步骤，重启后完整处决仍待实机验证。九尾妖狐作为独立后续调查记录，当前未声明兼容。

本地交付文件：

- `飞缘魔启动工具.exe`：独立 Windows x64 工具，需要 .NET Framework 4.x。
- `Nioh-HinoEnma-1.0.0-beta.5.4-source.zip`：完整选定源码快照、匹配 CT、构建方法、此次技术记录与逐文件验证信息。
- `使用说明.txt`：简明操作和验证边界。

升级先退出并重启游戏，在 NEW GAME/CONTINUE 主菜单启用本版，再继续游戏；已接入旧版的进程会提示重启。最后蛇头倒地后，锁定并靠近处决位置，轻按一次游戏原本的重攻击键（本次设置为 T），随后等待完整流程。其他时候仍保留飞缘魔旋转攻击。

本地离线验证通过 166 项完整源码回归、23 项处决测试和冻结的 59 项菜单/冷启动测试。23 项处决测试包含在 166 项中。Debug 与优化 Release 各通过 29 项自检、960 次当前载荷比较（12 布局）和 4632 次旧版载荷比较（72 布局）；源码/CT 和旧 60/71 处载荷保持验证通过。这些合成 CPU 检查不等同于重启后的游戏测试。

详见 [处决修复记录与九尾妖狐调查路径](../debugging/orochi-execution-2026-10-11.md)、[精确本地验证数据](../validation-beta5.4.json)、[构建与归档方法](../BUILD.md)。源码 ZIP 的 `build-info/` 标明精确源码快照、Debug/Release 哈希、三组便携验证、回归结果和交付 EXE 哈希。

本次为本地包，没有新 Git 提交、公开标签、GitHub Release 或 CI 来源证明。历史记录与发布资产保持原样。既有道具、菜单与其他功能的适配边界仍适用，CT 在 CE 内执行未实测，EXE 未作 Authenticode 签名。
