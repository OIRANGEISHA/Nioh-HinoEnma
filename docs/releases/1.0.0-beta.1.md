# Nioh Hino-Enma 1.0.0 Beta 1

Release Owner: **OIRANGEISHA**. Channel: **Beta / Pre-release**. Target: Windows x64, verified Steam Nioh Complete Edition 1.24.8 (window 1.24.08).

## Highlights / 主要变化

- First public standalone EXE, ZIP, guarded CT and source release for the current Hino-Enma adaptation.
- Preserve Hino-Enma's Boss model/moveset and add native player growth, armor and selected melee-weapon bonuses to Boss base values.
- 首个公开测试版，整合角色替换、已测试交互、飞行镜头、背包道具及属性叠加。

## Fixed / 修复

- Locally reported boxes, key doors, prison doors and one-sided doors can complete their original interaction flow; corpse loot is confirmed.
- Flight no longer forces the camera to look down. Bag Himorogi Fragment returns to mission selection; Kodama guide-home and bag Sacred Water are confirmed.
- The reported blood tomb now summons a revenant after hold completion, explicitly confirmed by the tester.
- Native weapon HUD refresh reads the selected saved-gear view; explicit final on-screen icon confirmation remains pending.

## Validation / 验证

- Actual local Windows Steam game: visible replacement and basic play, the listed interaction flows, flight camera, Himorogi Fragment, Kodama, Sacred Water, armor changes and the reported revenant summon.
- Prior local adaptation: 89 Python checks, 12 C# checks and 252 relocation comparisons. Local native-code tests used verified game snapshots; those proprietary/private research inputs are not distributed or described as CI.
- Public packaging retains the same 21 native payloads and signatures; only public version/UI/build metadata changes. Debug/Release builds and portable verification results are recorded in the build-provenance asset.
- This is functional validation of the known build, not complete multi-PC, every-item or every-affix validation.

## Known limitations / 已知限制

- Non-humanoid Boss life-drain grab failure, shortcut conflicts, incomplete interaction coverage and pending final weapon-icon display confirmation.
- Sacred Water is confirmed; Elixir healing and every other recovery/buff effect are not individually confirmed. Each affix, element and actual damage difference still needs testing.
- Ladders, dialogue, shrines, scripted events, all mission transitions, save/load cases and every tomb variant are not all tested. Direct CT enable inside CE is untested.
- Final public EXE cold first-enable after restarting Nioh is not separately tested. The current verified payload session and prior first-enable evidence are retained; no fresh-install claim is made.
- Unsigned Windows Beta. Protected Authenticode signing is not configured. An attestation, when supplied, identifies its CI build rather than certifying gameplay or Windows signing.
- Repository immutable-release enforcement is not assumed; the publication policy forbids replacing public tags/assets regardless of settings.
