# Beta 5.4.2 键位说明

沿用测试者当前的游戏键盘设置；修改过游戏绑定时可能不同。数字键指主键盘数字行。菜单预览无需新增按键。

| 按键 | 功能 |
| --- | --- |
| W／A／S／D | 移动 |
| J | 踢腿 |
| I | 挥伞 |
| K | 撤步／闪避 |
| Shift | 恢复精力 |
| Q＋空格 | 起飞 |
| Alt | 原有飞扑／俯冲 |
| 1 | 吸血；包括受支持的战后浓姬／雪女配对抓取动画 |
| 2（第一栏道具快捷位） | 使用兼容道具，当前唯一支持的道具快捷位置 |
| 5 | 地面及空中吼叫 |
| F6 | 净化附近常世；长按只触发一次，松开再按可重复 |
| 9 | 地面空闲、守护灵槽满时启动原生九十九并召唤守护灵攻击 |
| 游戏原本的重攻击键（本次为 T） | 九尾妖狐或八岐大蛇最后蛇头符合处决条件时请求原生处决；其余时候保留旋转攻击 |
| 游戏交互键，随后 W／S | 进入梯子后上爬／下爬 |

九十九期间，守护灵退场且人物恢复地面空闲后，松开再按 9 可重复召唤。上下梯结束后恢复飞缘魔招式。

**兼容道具放到第一栏的 2 号快捷位。** 用户已更正并实测确认此位置；其他快捷位保持飞缘魔技能或动作绑定。兼容道具也可在背包选“使用”；部分非关键道具使用仍未修复。

道场教学兼容：空格用于已反馈的残心／净化步骤，空格＋2／3用于近战切换教学，空格＋1／4用于远程切换教学，T用于九十九教学并保留原有攻击。教学兼容不等于实际切换 Boss 武器或接入原生射击。

These bindings follow the tester's game settings. Use main-row digits. Compatible item shortcuts support **slot 2 on the first item bar**; other slots retain Hino-Enma skills/moves. Digit **5** is ground/air roar, **F6** purifies nearby Yokai Realm pools, and **9** starts native Living Weapon/guardian attack when fully charged and idle on the ground. Release and press again after the guardian retires to repeat. Some non-critical item use remains unfixed.

九尾妖狐或大蛇最后蛇头倒地后，锁定并靠近处决位置，只按一次原本的重攻击键，随后等待动作与剧情完成。本次使用 T；九尾场景候选与正式 Release EXE 的完整重启复测均完成击杀、剧情继续和控制恢复，精确 EXE 与只读核对范围见[本地验证记录](validation-beta5.4.2.json)。Beta 5.4.2 未重新打完大蛇整场，保留代码及 CPU 路由核对独立于 Beta 5.4.1 的历史实测；八头完整战斗尚未逐一验证。

适配范围及验证限制见 [中文说明](../README.zh-CN.md) 和 [Beta 5.4.2 本地打包记录](releases/1.0.0-beta.5.4.2.md)。
