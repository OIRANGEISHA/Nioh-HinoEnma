# Beta 6 键位说明

Beta 6 新增十种已测试道具的兼容，键位保持原样，成长和修正 LV 计算沿用 Beta 5.6.3。以下早期版本的实测描述保留其原始版本身份；详细历史记录可在源码包 docs 目录查看。本次已获用户授权发布 GitHub Beta 6；新 EXE 仅完成离线检查，尚未完整重启实测。

沿用测试者当前的游戏键盘设置；修改过游戏绑定时可能不同。数字键指主键盘数字行。菜单预览无需新增按键。

| 按键 | 功能 |
| --- | --- |
| W／A／S／D | 移动 |
| J | 踢腿 |
| I | 挥伞 |
| K | 撤步／闪避 |
| Shift | 恢复精力 |
| Q＋空格 | 起飞 |
| Alt | 原有飞扑／俯冲 |
| 1 | 吸血；包括受支持的战后浓姬／雪女配对抓取动画 |
| 2（第一栏道具快捷位） | 使用兼容道具，当前唯一支持的道具快捷位置 |
| 5 | 地面及空中吼叫 |
| F6 | 净化附近常世；长按只触发一次，松开再按可重复 |
| 9 | 地面空闲、99量表充满时启动原生九十九，播放起手动画和冲击波；99期间满足条件可再次召唤守护灵 |
| 游戏原本的重攻击键（本次为 T） | 九尾妖狐或八岐大蛇最后蛇头符合处决条件时请求原生处决；其余时候保留旋转攻击 |
| 游戏交互键，随后 W／S | 进入梯子后上爬／下爬 |

Beta5.6.1 已完整重启验证数字 9 的起手动画、冲击波、量表显示与消耗及自然结束后的控制恢复，见[本次验收](living-weapon-beta561-gameplay.json)。实测为同一武器和守护灵、type 11／family 2，其他装备未全面测试。九十九期间，守护灵退场且人物恢复地面空闲后，松开再按 9 可重复召唤；本次修复保留这一功能。上下梯结束后恢复飞缘魔招式。

**兼容道具放到第一栏的 2 号快捷位。** 用户已更正并实测确认此位置；其他快捷位保持飞缘魔技能或动作绑定。兼容道具也可在背包选“使用”。本次从背包验证了切腹短刀、粪球、高贵的粪球、天狗的团扇、石头、火药弹、焙烙弹、焚火油壶、御箭护符和已测试的迟钝符。迟钝符仅覆盖本次定义；其他迟钝符变体、其他术及部分非关键道具尚未修复或验证，不代表所有道具或忍术均可使用。

道场教学兼容：空格用于已反馈的残心／净化步骤，空格＋2／3用于近战切换教学，空格＋1／4用于远程切换教学，T用于九十九教学并保留原有攻击。教学兼容不等于实际切换 Boss 武器或接入原生射击。

These bindings follow the tester's game settings. Use main-row digits. Compatible item shortcuts support **slot 2 on the first item bar**; other slots retain Hino-Enma skills/moves. Digit **5** is ground/air roar, **F6** purifies nearby Yokai Realm pools, and **9** starts native Living Weapon with its startup animation and shockwave when fully charged and idle on the ground. During active Living Weapon, release and press again after the guardian retires and the character returns to ground idle to summon again. Beta 6 adds the ten tested item definitions listed in the release notes, including one Sloth Talisman definition. Other variants, jutsu and some non-critical items remain unsupported or unverified.

九尾妖狐或大蛇最后蛇头倒地后，锁定并靠近处决位置，只按一次原本的重攻击键，随后等待动作与剧情完成。本次使用 T；九尾场景候选与正式 Release EXE 的完整重启复测均完成击杀、剧情继续和控制恢复，精确 EXE 与只读核对范围见[本地验证记录](validation-beta5.4.2.json)。Beta 5.4.2 未重新打完大蛇整场，保留代码及 CPU 路由核对独立于 Beta 5.4.1 的历史实测；八头完整战斗尚未逐一验证。

以上大蛇／九尾结果是原版本历史记录，本轮没有重新实测。当前适配范围及验证限制见[中文说明](../README.zh-CN.md)和[Beta 6 版本说明](releases/1.0.0-beta.6.md)。
