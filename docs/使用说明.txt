《仁王 1》飞缘魔操控工具 1.0.0 Beta 1
适配 Steam 完全版 1.24.8，游戏窗口显示 1.24.08。

1. 从 Steam 正常启动游戏，停在 NEW GAME / CONTINUE 主菜单。
2. 双击飞缘魔启动工具.exe，显示“已启用”后载入关卡。
3. 人物生成后变成飞缘魔，可以关闭工具。
4. 每次重启游戏后再运行一次。已经用威廉进入关卡时，先返回主菜单。

运行 EXE 不需要 CE 或 Python，不用替换启动器。访问失败时再尝试以管理员身份运行。
当前测试键位：J 踢腿，I 挥伞，K 闪避，Shift 恢复精力，Q＋空格起飞，1 吸血。

属性按 Boss 基础＋成长与装备加成计算，保留飞缘魔模型和招式。
已确认：当前箱子、钥匙门、监狱门、单侧门、尸体取物、飞行镜头、背包神篱碎片、木灵、御神水与反馈的血刀冢召唤。
限制：非人形 Boss 吸血、快捷键冲突、全部交互和每项词条/道具效果尚未全部解决或验证；最终武器图标显示仍待明确确认。
本 Beta 未作 Authenticode 签名，最终公开 EXE 在新游戏进程中的首次接入尚未单独实测。

人物替换机制来源：Bryanyora Character Change CT，当前版本重新适配。
