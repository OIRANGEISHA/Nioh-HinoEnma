使用方法
1. 从旧版升级时完整退出并重启游戏，停在 NEW GAME／CONTINUE 主菜单。
2. 运行本版 EXE，启用飞缘魔，再继续到地图或关卡。
3. 启用后可以关闭工具；每次重启游戏后再运行一次。
4. 切换角色时点击工具对应按钮，再返回主菜单继续，重新生成后生效。
运行只需要 Windows 64 位及 .NET Framework 4.x，不需要 CE、Python 或源码包。
同一进程不要混用版本或 EXE／CT；旧版安装身份会提示重启。

常用键位（数字键为主键盘数字行）
W/A/S/D：移动。J：踢腿。I：挥伞。K：撤步／闪避。
Shift：回复精力。Q＋空格：起飞。Alt：飞扑／俯冲。
1：吸血。5：地面及空中吼叫。F6：净化附近常世。
9：地面空闲、守护灵槽满时启动九十九并召唤守护灵攻击。
守护灵退场、人物恢复空闲后松开再按 9，可以重复召唤。
兼容道具放到第一栏的 2 号快捷位，或从背包选择使用。
其他快捷位仍绑定飞缘魔技能和动作。
上下梯使用游戏交互键，W 上爬、S 下爬；离梯后恢复招式。
道场空格兼容残心／净化，空格＋2／3近战切换教学，空格＋1／4远程切换教学。
T 兼容九十九教学并保留飞缘魔原有攻击。完整说明在源码包 docs/键位说明.md。
九尾妖狐或八岐大蛇最后蛇头倒地后，锁定并靠近处决位置，轻按一次游戏原重攻击键。
本次设置为 T。符合原生处决条件时进入处决链，其余时候为旋转攻击。
动作及剧情期间先不追加输入，等待控制恢复。
