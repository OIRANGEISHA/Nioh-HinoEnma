《仁王1》飞缘魔启动工具 Beta 6（1.0.0-beta.6）

适用版本：Steam《仁王：完整版》1.24.08，Windows x64。

1. 完整退出并重启游戏，停在 NEW GAME / CONTINUE 主菜单。
2. 运行本目录 EXE，启用飞缘魔后继续游戏。每次游戏重启后需要重新运行工具。
3. EXE 为独立工具，无需 Python 或 Cheat Engine。源码中的 CT 为可选开发形式，不与 EXE 同时启用。
4. GitHub Beta 6 附件为 EXE 和源码 ZIP；说明、键位、CT 和校验记录均在源码包中。

新增道具兼容：切腹短刀；粪球、高贵的粪球、天狗的团扇；石头、火药弹、焙烙弹、焚火油壶；御箭护符和本次已测试的迟钝符。切腹短刀死亡／神社复活和其余道具效果均由用户实测确认。迟钝符仅覆盖已测试定义，不代表其他变体或所有术均可使用。

成长规则：0—750 级线性映射 1—4525 档（0 仅为数学起点）。401 级起 Boss 基础生命 ×2、攻击 ×1.2，再叠加成长、装备和修正 LV。精力、防御采用原生曲线；保留自身更高原生档位。
体力、攻击、防御、幸运修正共享 1000 点上限，保持原生计算；保留选中武器的固定攻击收益。修正 LV 不参与普通等级映射或 401 级门槛，刷新不会主动补满当前生命。

常用键位：数字 1 吸血；数字 5 地面／空中吼叫；数字 9 九十九与守护灵；F6 净化常世；J 踢腿、I 挥伞；Q＋空格飞行。兼容道具从背包或第一栏数字 2 使用，其余快捷位仍保留技能。详见键位说明.md。

测试范围：本批修订已在运行中的游戏里实测通过，新 Beta 6 EXE 仅完成离线检查，尚未单独完整重启实测。此前成长、九十九、附魔、预览和交互修复继续保留，其历史测试不表示本轮全部重测。
已知限制：其他迟钝符定义、其他术及部分非关键道具尚未修复或验证；非标准装备、施法受击打断和所有场景未全面验证。具体构建身份与验证结果见随包记录。
