《仁王1》飞缘魔启动工具 Beta 6.1.3（1.0.0-beta.6.1.3）

适用版本：Steam《仁王：完整版》1.24.08，Windows x64。

1. 完整退出并重启游戏，停在 NEW GAME / CONTINUE 主菜单。
2. 运行本目录 EXE，启用飞缘魔后继续游戏。每次游戏重启后需要重新运行工具。
3. EXE 为独立工具，无需 Python 或 Cheat Engine。源码中的 CT 为可选开发形式，不与 EXE 同时启用。
4. GitHub Release 仅提供 EXE 和源码 ZIP；说明、键位、CT 和校验记录均包含在源码包中。

本次新增：粘液罐、散变符；封力符、活源符、封气符、宿心解放符、火／水／风／雷／土弹符、发气符。
散变符动作结束后松开再按第一栏数字 2，可连续施放，已连续四次测试正常。
宿心解放符保留原生光刃与当前武器爱用度消耗，至少需要 300 爱用度；用后不足时按钮变灰属于原生限制。
此前五种禁属性晴明符及已测试的施法受击恢复继续保留；它们没有显示数量，不以扣除数量判断成功。

保留修复：风箭符／克金符只有动作而未发射或扣除次数；使用已支持道具受击后误触撑伞、飞起或吼叫；移动后连续施法查找错误。
此前新增兼容：护灵招来符、污泥罐。守护灵召唤攻击、罐子投放与污泥效果、次数／数量扣除及使用后移动、J／I／数字 5 已由用户确认正常。
保留火炎龙术卷轴及此前术法修复。兼容只覆盖已核对定义，不代表其他同名变体或所有术均可使用。
保留 Beta 6 的切腹短刀、粪球／高贵的粪球／天狗团扇、四种投掷道具、御箭护符及已测试迟钝符修复。

成长规则：0—750 级线性映射 1—4525 档（0 仅为数学起点）。401 级起 Boss 基础生命 ×2、攻击 ×1.2，再叠加成长、装备和修正 LV。精力、防御采用原生曲线；保留自身更高原生档位。
体力、攻击、防御、幸运修正共享 1000 点上限，保持原生计算；保留选中武器的固定攻击收益。修正 LV 不参与普通等级映射或 401 级门槛，刷新不会主动补满当前生命。

常用键位：数字 1 吸血；数字 5 地面／空中吼叫；数字 9 九十九与守护灵；F6 净化常世；J 踢腿、I 挥伞；Q＋空格飞行。兼容道具从背包或第一栏数字 2 使用，其余快捷位仍保留技能。详见键位说明.md。

测试范围：本批修订已在运行中的游戏里实测通过，新 Beta 6.1.3 EXE 单独进行离线验证，尚未完整重启实测。此前成长、九十九、附魔、预览和交互修复继续保留，其历史测试不表示本轮全部重测。
已知限制：仍有部分阴阳术的使用尚未修复。其他同名定义、其他术及部分非关键道具尚未修复或验证；非标准装备、其他道具的每个受击分支和所有场景未全面验证。具体构建身份与验证结果见随包记录。
