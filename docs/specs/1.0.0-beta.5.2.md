Scope consumers to the current player and owned attack resources; bind cached values to current actor, component, epoch, selected weapon and native recalculation state. Skip invalid or racing cache reads and writes.
- Give valid temporary talisman or Living Weapon elements priority over the selected weapon's permanent element. Do not write the permanent value into the temporary-buff fields. Preserve Boss weapon rows, base-plus-growth/equipment calculation, selected-weapon attack increments and normal native refresh.
- Cover supported ordinary kicks, umbrella attacks and body charge using native primary enchantment priority. Cover the existing needle projectile and successful life-drain paths with their guards. Preserve needle paralysis and the roar's original effects; exclude the roar from added elements. Do not claim that ordinary body attacks gain independently stacked paralysis.

Separately check newly installed executable code and three writable, non-executable data pages. Do not claim live VirtualQuery verification of prior installations' page protection. Preserve repeated-enable behavior and scoped character choice without mixed-version writes.
- Retain keyboard bindings: digit 5 roar, digit 9 native Living Weapon and guardian attack, F6 purification. Compatible shortcut items remain in slot 2 on the **first** bar. Other skill/move shortcut conflicts stay unchanged. Some non-critical item use remains unfixed.
- Exclude credentials, saves, recorded process addresses, private sessions/raw logs, native-code/resource snapshots, game resources, dependency binaries and original third-party CT archives.
