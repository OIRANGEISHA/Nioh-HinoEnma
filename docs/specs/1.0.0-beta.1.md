# Beta 1 release specification

## Objective

Host the current locally tested Hino-Enma adaptation as the first public Beta under OIRANGEISHA/Nioh-HinoEnma. Public version is 1.0.0-beta.1; native behavior remains that of the verified private 0.14 adaptation.

## Scope

- Standalone Windows x64 EXE and ZIP, guarded CT, source, bilingual README, changelog and release records.
- Preserve player replacement, interaction compatibility, camera and item paths, and additive Boss-baseline attributes.
- Use an explicit public-file allowlist. Exclude private session records, process addresses, original game/code snapshots, archives, historical CT and dependency binaries.
- Produce source-linked hashes and provenance; use an annotated, non-replaced tag and Draft Pre-release.

## Verification

- Compare all public native payloads/signatures against the tested private profile.
- Regenerate the public C# profile; build Debug and optimized Release.
- Run portable self-checks and all 252 relocation comparisons.
- Review Beta version labels and the offscreen launcher preview.
- Verify the exact source commit, tag, upload identity, asset sizes/hashes and prerelease state before announcing completion.

## Boundaries

Steam 1.24.8/1.24.08 exact build only. Previously confirmed local gameplay is retained as historical evidence. No claim of every interaction/affix/item being verified. Final public EXE cold enable after a fresh game restart is not separately tested; its native payload equivalence and enabled-state recognition are the relevant current checks.
